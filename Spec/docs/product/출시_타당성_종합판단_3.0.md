# 출시 타당성 종합 판단 — 가치 · 리스크 · 타당성 (3.0 갱신)

Travel Fingerprint 3.0 스펙(여행 중 입력 제거 → 30초 평가 + 여행 원장 재생 + 랭킹 보드) 확정을 반영해 출시 타당성을 다시 판단했다. 근거는 3.0 스펙의 리스크 레지스터(10절)·로드맵(9절)과 2026년 7월 기준 공개 벤치마크(RevenueCat State of Subscription Apps, 여행 앱 리텐션 벤치마크).

결론은 초판과 같은 **조건부 GO**이되, 조건의 내용이 바뀌었다 — 초판의 최대 리스크였던 "여행 중 다회 입력의 비현실성"은 3.0 재설계로 해소됐고, 대신 **편집 프로필 품질**과 **평가 완료율**이 새 관문이 됐다.

| 가치 판단 | 핵심 리스크 | 개발 타당성 | 종합 판단 |
|---|---|---|---|
| **강함** | 구조적 2건 | **높음** (3.0에서 상승) | **조건부 GO** |

---

## 1. 가치 판단

"여행 취향의 자기이해 + 그에 근거한 다음 여행지 추천"이라는 포지션은 기록형(지도·사진)과 예약형(OTA) 사이의 빈 자리다. 3.0에서 가치가 실질적으로 강해진 지점은 **콜드스타트 해소** — 온보딩에서 과거 여행을 원탭으로 등록하면 첫날부터 지문·랭킹·추천이 존재하므로, 이 카테고리 앱들의 고질병인 "쌓일 때까지 빈 앱" 구간이 없다.

| 가치 항목 | 근거 | 강도 |
|---|---|---|
| 차별화된 자기이해 가치 | 취향 지문(5축) + 여행 랭킹 보드 + Wrapped 라이트. 기록/지도형 앱(Polarsteps 등)에 없는 축. 3.0의 온보딩 과거 여행 등록(사진 위치 스캔 원탭) 덕분에 가입 첫날부터 지문과 추천이 생겨 '빈 앱' 문제가 없음 | **강함** |
| 수익화 전환력 | 여행 카테고리 트라이얼→유료 전환 중앙값 48.7%로 전 카테고리 1위, 환불률도 최저(1.5%). 연간 구독 비중 65%로 장기 결제 수용성 높음 (RevenueCat 2025) | **강함** |
| 데이터 모트 | 불변 여행 원장(판정·서열·귀속 태그)이 쌓일수록 추천이 좋아지고, 랭킹 보드 조정이 과거 라벨을 계속 교정하는 구조. 이력 이전이 불가능해 전환비용이 자연 형성됨 | 중간~강함 |
| 체감 루프의 설득력 | 유저가 고른 태그 언어가 추천 사유로 되돌아오고('교토에서 골랐던 고요함·미식과 닮은 나라'), 평가 직후 지문 델타 + 추천 즉시 갱신. '내 입력이 반영된다'는 인과가 30초 안에 보임 | 중간~강함 |
| 바이럴/공유 유인 | Wrapped형 '올해의 여행 랭킹' 카드 공유 + 하루 한 장 사진이 첫해부터 Wrapped 내용물을 채움. 다만 공유 루프 자체는 검증 전 가설 | 중간 |

## 2. 리스크 판단

여행 앱 시장의 핵심 역설: **돈은 내는데(전환율 전 카테고리 1위) 돌아오지 않는다(Day 30 리텐션 최하위권).**

| 지표 | 여행 카테고리 | 전체 앱 평균 |
|---|---|---|
| Day 1 리텐션 | 18% | ~26% |
| Day 7 리텐션 | 7.6% | ~12% |
| Day 30 리텐션 | 3~5% | ~6% |
| 트라이얼→유료 전환 | **48.7% (1위)** | ~30% |

> 출처: 리텐션 — ASD "Improving Travel App Retention Rate 2026" 및 Adjust·Sendbird 계열 집계 · 전환율 — RevenueCat State of Subscription Apps 2025. 기준 시점 2026-07. 출처별 편차가 커 방향성 참고용.

### 리스크 레지스터 (출시 관점)

| 리스크 | 분류 | 현황 / 근거 | 대응 (3.0 스펙 반영) |
|---|---|---|---|
| 편집 프로필 = 단일 실패 지점 | 🔴 구조적 | Stage 0에서 국가 프로필이 편집 동결이므로, 여행 신호 x_t가 전부 편집 라벨에서 파생됨. 국가 라벨링과 태그→축 서명 매핑의 오류가 UTV·추천에 양방향 전파 (스펙 리스크 #1·#2) | 30개국 파일럿의 2인 검수 게이트에 태그 어휘 서명까지 편입. 통과 국가만 노출, 나머지는 회색 처리. 개발 착수 전 선행 — 이 게이트가 사실상 GO/NO-GO 관문 |
| 리텐션 구조적 취약성 | 🔴 구조적 | 여행 앱 Day 30 리텐션 업계 3~5%(전 카테고리 최하위권). 여행이 연 1~3회의 episodic 행동이라 N-day 지표 자체가 불리 | 비여행 접점(추천 카드 반응 + 랭킹 보드) + 여행 중 접점(하루 한 장) + 연말 Wrapped. 재방문율을 N-day가 아닌 '여행 사이클 단위'로 측정 |
| 평가 스킵률 → 라벨 기근 | 🟠 설계로 관리 | 30초 평가가 여행당 유일한 취향 입력. 스킵률이 높으면 학습이 굶고, 3.0은 여행 중 신호가 없어 대체 소스도 없음 (스펙 리스크 #7) | 여행 감지→평가 유도 알림(배관), 하루 한 장 사진을 회고 배경으로 깔아 완료율 지원. 스킵 시에도 방문 사실은 원장 기록 + s̃_t 중앙값 대체. 평가 완료율이 v1.5 스토리 승격 트리거 |
| 양성 쏠림 | 🟠 설계로 관리 | 만족 여행만 기록되면 지문이 '취향'이 아닌 '방문 이력 평균'으로 퇴화 (스펙 리스크 #4) | 부정 태그(≤3) + 카드 '싫어요' UI 상시 노출 + 서열 하위 여행의 음성 게인 — 음성 신호 3원 확보. 부정 태그 수집률을 핵심 KPI로 |
| 개인정보/권한 장벽 | 🟠 설계로 관리 | 온보딩 사진 스캔(사진첩) + 여행 감지(위치)가 핵심 UX인데, 권한 거부 시 콜드스타트·배관이 약화. Privacy Nutrition Label, PrivacyInfo.xcprivacy, EU 대상 시 GDPR opt-in 필수 | 온-디바이스 스캔(위치 데이터 서버 미전송)을 명시하는 프라이밍 화면 — 이 경계가 수락률을 좌우. 거부 시 수동 등록 폴백이 이미 스펙에 존재. 사진 분석 없음(참조만)이라 규제 부담 낮음 |
| 파라미터 추측값 스택 | 🟠 설계로 관리 | k, δ, λ, ±0.15, 태그 리프트 기준, g(s̃) 곡선 등 검증 안 된 상수가 겹겹이 쌓임 (스펙 리스크 #5) | 전부 원격 설정으로 분리 + utv_recomputed 델타 로깅으로 수렴 관측. UTV가 원장 재생 모델이라 파라미터 변경 시 무손실 재계산 가능 — 3.0에서 이 리스크의 비용이 크게 하락 |
| 대형 플레이어 카피 | 🔵 경쟁/참고 | Tripadvisor·Wanderlog 등이 AI 추천을 빠르게 확장 중. 기능 표면(취향 퀴즈, AI 일정)은 모방이 쉬움 | 모방이 어려운 것은 개인의 여행 원장(평가·서열·태그 이력). 데이터 자산으로 방어하되, 초기엔 니치(자기이해·기록) 포지셔닝으로 정면 경쟁 회피 |
| 실행 리소스 | 🔵 경쟁/참고 | 파일럿 라벨링 + 추천 로직 + 앱 + 심사를 소규모 팀이 감당해야 함 | 3.0에서 여행 중 슬라이더·사진 분석·Trip Mode가 제거돼 MVP 스코프가 초판 대비 축소. CF는 Stage 2로 이연. 파일럿 라벨링만 개발과 병행 불가한 선행 작업 |

> 🔴 구조적(사업 성패 직결) · 🟠 설계로 관리 가능 · 🔵 경쟁/실행상 참고. 스펙 10절 리스크 레지스터(9건)와 동기화 — 다구간 귀속 오염(#9), 하루 한 장 압박 변질(#8) 등 제품 내부 리스크는 스펙에서 이미 완화책이 확정돼 여기선 생략.

## 3. 타당성 판단

| 축 | 판단 | 근거 |
|---|---|---|
| 기술 | **높음** (3.0에서 상승) | 입력이 전부 원탭/태그이고 UTV는 유저당 수십 건의 결정적 재생(fold)이라 1인~소규모 팀도 구현 가능. 온보딩 사진 스캔도 온-디바이스 EXIF 군집화 수준. ML 학습 파이프라인 불필요(규칙 기반 스코어링) |
| 초기 데이터 | 중간 — **파일럿이 관문** | 국가 프로필 + 태그 어휘 축 서명의 편집 품질이 시스템 전체의 상한선. 30개국 파일럿 통과 기준 4종(축 분산/유저 분산/설명 품질/검수 재현성)을 먼저 통과해야 함. 유저 측 콜드스타트는 온보딩 과거 등록으로 해소됨 |
| 규제/심사 | 중간~높음 | 사진첩·위치·알림 권한 모두 표준 매니페스트와 맥락 프라이밍으로 대응 가능한 범위. 위치는 SLC/Region Monitoring 수준의 저전력 감지라 백그라운드 추적 이슈도 제한적. EU 대상 시 opt-in 플로우만 추가 |
| 수익화 | 전환 높음 / 유지 미검증 | 전환율은 카테고리 1위(48.7%)·환불률 최저지만, 여행 비수기 해지가 관건. 연간 구독 지배적(65%) 카테고리 특성 + Wrapped 시점 가치 리마인드로 갱신 방어 |
| 일정/리소스 | 높음 | MVP 범위(온보딩 등록 + 30초 평가 + 3슬롯 + 랭킹 보드 + 하루 한 장 + Wrapped 라이트)는 소규모 팀 기준 수 주~수개월 범위. 단, 파일럿 라벨링이 선행 게이트라 캘린더 상 직렬 구간이 존재 |

## 4. 최종 판단: 조건부 GO

> [!success] 출시를 권장한다 — 단, 아래 4개 게이트를 순서대로 통과하는 조건
> 3.0은 초판 대비 스코프가 줄고(슬라이더·사진 분석·Trip Mode 제거) 검증 가능성은 올라간(원장 재생 = 무손실 재계산, 파라미터 원격 설정) 구조라, "작게 출시하고 데이터로 확장 판단"이 실제로 가능해졌다. 아래 게이트는 스펙의 파일럿 기준·KPI·v1.5 승격 트리거를 출시 의사결정 관문으로 재배열한 것.

| 게이트 | 통과 기준 | 미통과 시 대응 |
|---|---|---|
| **G1 — 파일럿 게이트** (개발 착수 전) | 30개국 프로필 + 태그 어휘 축 서명이 2인 검수·통과 기준 4종을 통과. 조건부 축(energyLevel 등)의 생존 여부도 여기서 확정 | 통과 국가만으로 축소 출시 또는 축 구성 재설계. DB 스키마 확정은 이 결과 이후 |
| **G2 — 온보딩 게이트** (베타) | 사진 권한 수락률 + 과거 여행 3개 이상 등록 완료율. 콜드스타트 해소 장치가 실제로 작동하는지 검증 | 프라이밍 카피/수동 폴백 UX 개선. 이 게이트가 무너지면 '첫날부터 추천'이라는 핵심 약속이 무너짐 |
| **G3 — 라벨 게이트** (출시 후 1~2 여행 사이클) | 평가 완료율(스킵률), 서열 응답률, 부정 태그 수집률. 학습이 굶지 않는지 확인 | v1.5 스토리(moment_logged) 재도입을 앞당김 — 스펙에 승격 트리거가 이미 명시돼 있음 |
| **G4 — 체감 게이트** (출시 후) | 저장 전환율, 재열람율, 랭킹 보드 조정률. '지문이 나를 안다'는 체감이 재방문을 만드는지 검증 | 체감 루프 4장치(태그 순환, 즉시 반영, 예측 책임지기, Wrapped) 우선 보강. 이 게이트가 리텐션 리스크의 실질 방어선 |

### 게이트와 무관하게 지킬 원칙 2가지

1. **LLM은 표현 계층에만.** 국가 프로필 초안, 추천 사유 문장에만 사용하고, 핵심 스코어링(원장 재생 EMA, 코사인 매칭, 태그 리프트)은 규칙 기반으로 유지한다. 추천의 재현성과 디버깅 가능성이 이 제품의 신뢰 기반.
2. **연간 구독 + 평생결제 혼합.** 여행 비수기 해지를 헷지하고, 갱신 시점을 Wrapped(연말 여행 랭킹) 발송과 정렬해 "1년치 가치"를 리마인드한다.
