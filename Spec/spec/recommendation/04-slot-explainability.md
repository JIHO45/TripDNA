# 3슬롯 결과 화면 — 태그 언어 기반 설명 체계

전제: [3.0 스펙](../../docs/product/Travel_Fingerprint_3.0_Spec.md) 5·6절. 취향 매치와 현실 적합도를
분리 표기하는 원칙은 유지하되, 설명의 어휘를 **유저가 평가에서 직접 고른 태그**로
전환합니다 (태그 언어의 순환 — 체감 루프 1번 장치).

## 1. 점수 분리 원칙 (유지 + 개정)

| 구분 | 이름 | 구성 요소 | 랭킹 영향 |
|---|---|---|---|
| 취향 매치 | Match Score | tasteFit(축별 신뢰도 c_a 가중) + interestFit | 슬롯 내 정렬 기준 |
| 현실 적합도 | Fit Tags | budgetFit / seasonFit / companionFit | 하드 필터 + 배지로만 노출 |
| 안전 정보 | Safety Notice | safetyFloor | 하한 미달 시 후보 제외, UI엔 링크만 |

개정: Match Score의 tasteFit은 [spec/02](../signal/02-signal-quality-and-aggregation.md) 4.4의
축별 신뢰도를 곱해 계산합니다. 데이터 적은 축이 매치율을 부풀리지 않습니다.

## 2. 설명 카피 — 태그 언어 순환

각 카드의 설명은 다음 우선순위로 생성합니다.

1. **유저 태그 인용** (최우선): 유저가 랭킹 상위 여행에서 골랐던 태그와 후보국 태그
   프로필의 교집합. — "교토에서 골랐던 `고요함`·`미식`, 이 나라와 닮았어요"
2. **랭킹 앵커**: 후보국과 가장 유사한 유저의 상위권 여행 인용. — "당신의 역대 1위
   조지아와 취향 지도가 가까워요"
3. **축 기여** (폴백, 태그 데이터 부족 시): 기여 상위 축 이름. — "자연 성향과 잘 맞아요"
4. **정직한 각주**: 해당 국가의 부정 태그 리프트가 높은 항목은 숨기지 않고 부가.
   — "단, 성수기 혼잡 주의" (신뢰 자산, 국가 품질 집계 재사용)

## 3. 슬롯별 카피 템플릿

| 슬롯 | 정의 (3.0 유지) | 템플릿 |
|---|---|---|
| `best_match` | 종합 최고점 | "취향 매치 {match}% — {교집합 태그} 취향과 가장 잘 맞아요" |
| `fresh_stretch` | tasteFit 하한 통과 내 noveltyBoost 최고 | "지금까지와 다르지만, `{새 태그}` 쪽으로 넓혀볼 만해요" |
| `underrated_fit` | 저인기 + interestFit/contextFit 우수 | "많이 알려지진 않았지만 `{태그}` 취향이면 꽤 잘 맞아요" |

중복 페널티/순차 배제 제외 사유 로깅(`excluded_reason`)은 기존 유지.

## 4. "fresh_stretch" 탐험 반경 개인화 (유지)

`exploration_affinity` 메커니즘은 구버전 그대로 유지합니다.

```
exploration_affinity_t = clamp(prev + δ_accept * accepted, 0, 1)
exploration_radius = base_radius * (0.6 + 0.8 * exploration_affinity_t)
```

개정 1건: `noveltyAppetite` 축이 파일럿을 통과하면 `exploration_affinity` 초기값을
축 값에서 유도합니다 (별도 콜드스타트 불필요).

`skip`은 지금 이 카드를 넘기는 UI 동작일 뿐 음성 취향 신호로 사용하지 않습니다. 같은 국가가
다음 세트에 다시 나올 수 있습니다. `dislike`만 180일 후보 제외 + 이후 강한 감점으로 처리하며,
유저가 설정에서 제외를 해제할 수 있어야 합니다.

## 5. 예측 책임지기 (신규 화면 요소)

추천했던 나라를 유저가 실제 방문하고 평가하면:

- 카드에 "예측 {match}% ↔ 실제 랭킹 {n}위 진입" 대조 표시.
- 크게 어긋난 경우 "지문을 이렇게 조정했어요" 델타를 함께 노출 — 틀림도 체감 재료.
- 데이터는 `recommendation_feedback`(saved) → `trip_evaluated` 연결로 산출,
  [spec/03](../signal/03-ema-experiment-design.md)의 2차 지표와 동일 소스.

## 6. 실험 연동

- 실험 B: 태그 언어 설명 vs 축 이름 설명 vs 단일 점수. 1차 지표는 저장 전환율과
  상세 체류시간, 보조는 설명 이해도 설문.
- 실험 C: 고정 반경 vs `exploration_affinity` 개인화 (기존 유지).

## 7. 확정이 필요한 항목

- Fit Tags 3단계 임계값 (구버전 미결 승계)
- 태그 인용 최소 조건 (교집합 태그 몇 개부터 1순위 카피 사용할지)
- 부정 각주 노출 임계 (부정 태그 리프트 얼마 이상일 때 표시할지)
