# 귀속 태그 어휘 — 축 서명 및 라우팅 (초안, 파일럿 검수 대상)

전제: [3.0 스펙](../../docs/product/Travel_Fingerprint_3.0_Spec.md) 2.2절. 태그는 여행 평가에서
"특히 좋았던 것 ≤5개 / 아쉬웠던 것 ≤3개"로 선택되며, 유일한 축 계측 수단이자
Interest Tags 갱신 소스, 추천 설명의 어휘입니다.

**이 문서 전체가 국가 프로필과 동일한 편집 산출물이므로, 30개국 파일럿의 2인 검수
게이트를 함께 통과해야 합니다** (3.0 스펙 7절 추가1, 리스크 레지스터 #2).

## 1. 설계 규칙

1. **양극 커버리지**: 조건부 Taste Core 축 4개(energyLevel, planningStyle, socialMode,
   noveltyAppetite)는 양극 태그가 최소 1쌍씩 존재해야 함 (1.4절 체크리스트).
2. **라우팅 3갈래**: 모든 태그는 `taste`(UTV 축) / `constraint`(상황) / `quality`(국가 품질) 중
   하나 이상으로 사전 라우팅. quality·constraint 태그는 **UTV 축을 건드리지 않음**.
3. **선택 경쟁 방어**: 평가 UI에서 양극(성향) 태그와 관심사 태그를 **별도 그룹으로 노출**
   (리스크 #3). 그룹별 선택률을 모니터링해 노출 순서를 조정.
4. 축 서명 값은 -1.0~1.0 (해당 축 방향으로의 끌림 강도). 초안 값이며 검수로 확정.

## 2. 관심사 태그 (Interest Tags 직결, 긍정/부정 겸용)

| 태그 | 라우팅 | 축 서명 (보조) | 부정형 표기 예 |
|---|---|---|---|
| `food` 미식 | taste+interest | — | 음식이 아쉬웠어요 |
| `culture` 문화/예술 | interest | — | — |
| `history` 역사/유적 | interest | — | — |
| `outdoor` 자연/트레킹 | taste+interest | natureUrban -0.6 | — |
| `beach` 해변/휴양 | taste+interest | natureUrban -0.4, energyLevel -0.4 | — |
| `nightlife` 밤문화 | taste+interest | energyLevel +0.6 | — |
| `shopping` 쇼핑 | taste+interest | natureUrban +0.4 | — |
| `wellness` 휴식/웰니스 | taste+interest | energyLevel -0.6 | — |
| `sportsAndEvents` 스포츠/페스티벌 직관 | taste+interest | energyLevel +0.4 | — |

> `localHiddenGem`은 관심사가 아니라 새로움 추구 **성향**에 가깝고 국가 간 변별력도 약해
> 삭제 — 의미는 3절 noveltyAppetite 양극(+) 카피에 흡수. `sportsAndEvents`는 방문 목적성이
> 뚜렷한 관심사로 신규 편입 (시즌 의존성 큼 — seasonFit 상호작용은 추천 로직 숙제).

## 3. 성향(양극) 태그 — 조건부 축 계측용, 별도 그룹 노출

카피는 **명사형 숏 카피**를 사용합니다 — 12~16개 칩이 깔리는 화면에서 문장형은
텍스트량이 많아 스캔을 포기하게 만들어 30초 예산을 위협하기 때문 (인지 부하 경량화).

| 축 | 양극 태그 쌍 (긍정 선택 시 서명) |
|---|---|
| `energyLevel` | `고요한 평화` (-0.8) ↔ `에너지 넘치는 자극` (+0.8) |
| `planningStyle` | `무계획의 묘미` (-0.8) ↔ `알찬 계획과 실행` (+0.8) |
| `socialMode` | `혼자만의 여유` (-0.8) ↔ `함께하는 즐거움` (+0.8) |
| `noveltyAppetite` | `편안한 익숙함` (-0.7) ↔ `낯선 새로움 · 숨은 명소 탐험` (+0.7) — 구 `localHiddenGem` 흡수 |
| `natureUrban` (확정축 보강) | `대자연의 감동` (-0.8) ↔ `도시의 매력` (+0.8) |

부정 방향 신호는 명사형 카피를 재사용하지 않습니다 — "아쉬웠던 것: 무계획의 묘미"는
성립하지 않으므로, 부정 화면에서는 4절의 부정 전용 태그가 반대 방향 음성 게인을 담당합니다
(예: `너무 북적였어요` → socialMode 음의 게인, 4.2절 축별 게인).

## 4. 부정 전용 태그 — 라우팅 주의

| 태그 | 라우팅 | 반영처 |
|---|---|---|
| `너무 북적였어요` | taste | socialMode/energyLevel 음성 게인 |
| `너무 심심했어요` | taste | energyLevel 방향 재조정 |
| `일정이 너무 빡셌어요` | taste | energyLevel 음성 게인 (`너무 심심했어요`의 반대 극 — 대칭성 확보) |
| `계획대로 안 돼서 힘들었어요` | taste | planningStyle 양성 게인. 외부 요인(날씨·파업) 오귀속 가능성이 있어 게인 보수적 시작 (±0.5 이하) |
| `날씨가 아쉬웠어요` | **constraint** | seasonFit — 시기 문제, 취향/국가 축 오염 금지 |
| `예상보다 비쌌어요` | **constraint** | budgetFit 개인 민감도 보정 |
| `이동이 힘들었어요` | constraint | flightFriction/여행 피로 — UTV 반영 없음 |
| `바가지/불친절` | **quality** | 국가 품질 점수 집계만 |
| `위생이 아쉬웠어요` | **quality** | 국가 품질 점수 집계만 |
| `인프라가 부족해 불편했어요` | **quality** | 국가 품질 점수 집계만. natureUrban 게인 금지 — 인프라 불만 ≠ 도시 선호(대자연 선호자도 불만 가능)이고, taste+quality 이중 라우팅은 같은 불만의 이중 계상 |

## 5. 노출 규칙

- 여행당 12~16개 노출: 성향 그룹 5쌍 중 상황 맞는 4~5개 + 관심사 그룹 7~8개.
- 방문국의 편집 프로필 기준 "그 나라에서 물어볼 가치가 높은" 태그를 우선 노출하되,
  양극 쌍은 반드시 쌍으로 노출 (한쪽만 노출하면 유도 편향).
- **와일드카드 슬롯 (노출 편향 방어)**: 프로필 기준 우선 노출만 하면 결측이 체계적이
  됩니다 — 파리(도시/예술 프로필)에서 숲과 공원만 즐긴 유저의 자연 취향은 nature 태그가
  노출되지 않는 한 영원히 관측 불가. 이를 막기 위해 12~16개 예산 **안에서** 1~2개는
  방문국 프로필 우선순위와 무관하게 배정합니다.
  - 선정 기준: 랜덤이 아니라 정보 이득 최대화 — 해당 유저의 축별 신뢰도가 낮은 축의
    양극 쌍, 또는 선택 이력이 없는 관심사 태그 우선.
  - 단 그 나라에서 성립 가능한 태그로 제한 (내륙 사막국에 `beach` 노출은 노이즈).
  - **여행 컨텍스트 모순 배제**: 등록된 여행의 동행 정보(`trip_started`)와 모순되는 태그
    제외 — 동행='가족/친구/커플'인 여행에 `혼자만의 여유` 와일드카드가 뜨면 탐색이 아니라
    버그로 인식됨. 동행 있는 여행의 socialMode 신호는 어차피 오귀속 보정 대상(3.0 스펙
    2.5절)이라 계측 가치도 낮음 — 정보 이득 기준과 일관됨. 단 배제는 이런 **명시적 모순의
    최소 목록**으로 한정. 추측성 배제(예: "가족 여행이니 `nightlife` 제외")를 넓히면
    와일드카드가 막으려던 체계적 결측을 배제 규칙이 재생산함.
  - 와일드카드 출신 선택은 별도 플래그로 로깅 — 선택률이 유의미하면 장치 유지,
    0에 수렴하면 제거 (데이터로 존치 판단).
- 부정 태그 화면은 긍정 다음, 선택 사항, 최대 3개.

## 6. 확정이 필요한 항목

- 축 서명 초안 값 전체 (2인 검수) — 신규 태그(`sportsAndEvents`, 부정 태그 2종) 포함
- 태그별 한국어 최종 카피 (UX 라이팅) — 명사형 숏 카피(3절)의 가독성/선택률 검증 포함
- 노출 우선순위 알고리즘의 구체 규칙 + 와일드카드 슬롯 선정 로직 세부 (5절)
