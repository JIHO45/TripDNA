# UTV 반영식 실험 설계 (실험 A′)

목표: [spec/02](02-signal-quality-and-aggregation.md)의 서열 보정 + 축별 게인 모델이
단순 반영식 대비 추천 품질을 실제로 올리는지 검증합니다.
구버전 실험 A(여행 중 다회 슬라이더의 품질가중 e_t)는 입력 메커니즘 폐기로 무효화되어
이 문서로 대체됩니다.

## 1. 실험 arm 정의

| 항목 | Simple (control) | Calibrated (treatment) |
|---|---|---|
| 만족도 | 절대값 (satisfaction-1)/4 그대로 | 서열 보정 s̃_t (w_rank=0.7) |
| 게인 | 전 축 동일 g(s) | 축별 게인 g_a (긍정/부정 태그 반영) |
| x_t | Profile_방문국 그대로 | Profile_방문국 + 태그 서명 보정 (α_pos) |
| 재생 구조 | 동일 (원장 재생) | 동일 |
| λ 스케줄 | 동일 (기존 유지) | 동일 |

두 arm 모두 원장 재생 구조는 공유합니다 — 실험 대상은 **재생에 들어가는 신호의 정제 방식**입니다.
원장이 불변이므로 실험 종료 후 패자 arm 유저도 승자 방식으로 무손실 재계산 가능합니다.
(구버전의 "기존 유저 UTV 소급 처리" 미결 문제가 재생 구조 덕분에 자동 해소됨.)

## 2. 피처 플래그

```
utv_signal_mode: "simple" | "calibrated"   # 유저 단위 할당, 원장 재생 시 일관 적용
```

- 한 유저는 실험 기간 내내 같은 arm (시계열 오염 방지).
- spec/02 7절의 상수 전체를 원격 설정으로 분리, 재배포 없이 튜닝.

## 3. 실험 설계

- **할당**: 신규 가입 유저 50:50, 지역/온보딩 채널로 층화.
- **관찰 조건**: 유저당 평가(온보딩 백필 포함) 5회 이상 누적 코호트를 주 분석 대상으로.
  온보딩 과거 등록 덕분에 구버전처럼 "여행 3회를 기다리는" 병목이 없습니다 —
  첫 세션에 5회 도달 유저가 다수일 것으로 예상.
- **1차 지표**: 추천 저장 전환율, `best_match` 슬롯 저장률.
- **2차 지표**: 예측 검증 정확도 — 추천 후 실제 방문한 여행의 s̃_t가 추천 시점 예측과
  일치하는 비율 (3.0 스펙 6절 "예측 책임지기"의 데이터 버전, 장기 지표).
- **가드레일**: 평가 완료율(스킵률) — calibrated arm의 서열 질문이 이탈을 만드는지.
  5%p 이상 하락 시 서열 질문을 선택 사항으로 강등.
- **롤백 기준**: 저장 전환율 유의 하락 또는 평가 완료율 5%p 하락.

## 4. 랭킹 보드 파생 실험 (실험 E, 신규)

- 대상: 랭킹 보드 노출 여부 (calibrated arm 내 50:50).
- 가설: 보드 노출군이 라벨 교정을 통해 장기 추천 품질이 높고, 비여행 기간 재방문율이 높다.
- 지표: `ranking_adjusted` 발생률, 조정 후 재생 델타 크기 분포, 재방문율.

## 5. 롤아웃 순서

1. 내부 도그푸딩 (calibrated 강제) — 원장/재생 정합성, `utv_recomputed` 델타 로그 확인
2. 신규 유저 10% treatment → 이상 없으면 50:50, 최소 4주
3. 가드레일 통과 시 100% calibrated, simple 경로는 1릴리스 유지 후 제거
