# UI-3. 메인·지문·여행 랭킹

## 1. 목적

유저가 앱을 열었을 때 현재 여행 상태와 다음 행동을 바로 이해하고, 자신의 지문과 여행 랭킹을
확인·교정하도록 합니다.

근거: [3.0 스펙 2.4·6절](../../../docs/product/Travel_Fingerprint_3.0_Spec.md),
[신호 재생 규칙](../../signal/02-signal-quality-and-aggregation.md)

## 2. 메인 UI

### UI-3A. 홈

첫 화면 높이 안에서 핵심 상태를 파악하도록 구성합니다. 추천·여행 목록은 하단 탭에 있으므로
홈에서 반복하지 않습니다.

1. **상단 바**
   - 인사 또는 현재 시즌 문구
   - 프로필/설정 버튼
   - 동기화 대기 시 작은 상태 아이콘
2. **간소화된 여행 지문**
   - 5축 지문 미니 시각화
   - 대표 문장: `당신은 고요한 자연 쪽에 가까워요`
   - 낮은 신뢰도 축은 작은 흐림 표시
   - 카드 전체 탭 → `지문 자세히 보기`
3. **상태 기반 주 행동 카드**
   - 평가 대기 여행 있음 → `포르투갈 여행을 평가해 주세요`
   - 현재 여행 있음 → `오늘의 한 장 고르기`
   - 예정 여행 있음 → `여행 일정 확인`
   - 아무것도 없음 → 고정 행동 카드를 노출하지 않고 `여행 탭에서 첫 여행을 등록해보세요` 안내
   - 신규 여행 등록은 하단 여행 탭의 고정 버튼에서 제공
4. **추천 1장**
   - best_match 카드 1장
   - 카드 탭 → 추천 탭의 3슬롯
5. **연간 Wrapped 진입 — 계절 조건부**
   - 12월 15일~다음 해 1월 15일이면서 해당 연도 여행이 1개 이상일 때만 노출
   - 그 외 기간에는 자리 자체를 만들지 않음

홈은 피드처럼 무한 스크롤하지 않으며 기본 상태에서 한 화면에 들어오는 것을 목표로 합니다.
Wrapped가 노출되는 기간에만 한 화면을 조금 넘길 수 있습니다.

## 3. 서브 UI — 지문

### UI-3B. 지문 상세

- 상단: 큰 여행 지문 시각화
- 축별 행:
  - 자연 ↔ 도시
  - 고요 ↔ 활동
  - 즉흥 ↔ 계획
  - 혼자/소수 ↔ 함께/사람 많은 경험
  - 익숙함 ↔ 새로움
- 각 행: 현재 위치, 신뢰도, 근거 여행/태그
- 조건부축에는 `현재 추천 점수에는 반영하지 않아요` 정보 아이콘
- 섹션:
  - `내 취향을 만든 여행`
  - `자주 고른 태그`
  - `아직 흐린 축`
- CTA: `내 여행 랭킹 확인`

유저가 축 값을 슬라이더로 직접 수정하는 기능은 제공하지 않습니다. 수정은 과거 여행 평가와
랭킹 보드에서 이뤄집니다.

### UI-3C. 축 상세 바텀시트

- 축의 양극 의미
- 현재 값과 신뢰도
- 근거가 된 상위 여행 2~3개
- 신뢰도가 낮을 때: `여행 평가가 쌓이면 더 선명해져요`
- 직접 설정 CTA 없음

### UI-3D. 지문 변화

평가 또는 랭킹 조정 직후 표시합니다.

- 이전 지문과 새 지문 오버레이
- 움직인 축과 방향
- 원인 문구: `포르투갈에서 고른 미식·도시의 매력이 반영됐어요`
- CTA: `업데이트된 추천 보기`
- 변경이 미미하면 과장하지 않고 `지문은 거의 그대로예요`

## 4. 서브 UI — 여행 랭킹

### UI-3E. 랭킹 보드

- 제목: `내 여행 랭킹`
- 설명: `순서를 바꾸면 취향 지문도 함께 조정돼요`
- 리스트 항목:
  - 순위
  - 대표 사진
  - 여행명(다국가면 `포르투갈 · 스페인`)
  - 기간
  - 만족도
  - 드래그 핸들
- 조작: 길게 누르고 드래그
- 드래그 중: 상단 미니 지문이 예상 결과를 실시간 미리보기
- 미리보기는 로컬 임시 계산이며 원장·UTV 캐시에 저장하지 않음
- 빠른 연속 이동은 디바운스해 마지막 순서만 계산
- 하단 고정 CTA: `이 순서로 저장`
- 편집 전에는 CTA 숨김 또는 비활성화

랭킹 단위는 국가가 아니라 **여행 1건**입니다.

### UI-3F. 랭킹 저장 결과

- 세션 종료 시 한 번만 UTV 재생
- 변경 전후 지문 델타
- 문구: `랭킹 조정으로 지문이 이렇게 변했어요`
- CTA: `완료`
- 인접 순위 이동으로 변화가 작으면 그대로 정직하게 표시

드래그 중 미리보기는 방향을 이해시키는 예상치이고, 저장 후 원장 전체를 재생한 결과가
최종값입니다. 둘이 달라지면 저장 결과를 기준으로 합니다.

### UI-3G. 여행 상세

랭킹 항목 탭 시 표시합니다.

- 대표 사진/하루 한 장 스트립
- 국가·도시·기간·동행
- 만족도, 다시 가고 싶은지
- 좋았던/아쉬웠던 태그
- 랭킹 위치
- 평가가 없으면 `평가하기`
- 대표 사진을 사용한 세로형 여행 카드 `공유하기`
- 공유 전 여행지명·기간·사진 공개 범위 확인
- 원장 삭제는 MVP에서 제공하지 않고 수정 정책 확정 전까지 읽기 중심

## 5. 상태별 홈

| 상태 | 우선 카드 |
|---|---|
| 신규·기록 없음 | 여행 탭의 첫 여행 등록 경로 안내 |
| 평가 대기 | 종료 평가 |
| 현재 여행 | 오늘의 한 장 |
| 예정 여행 | 여행 일정·알림 안내 |
| 일반 상태 | 추천 1장 |
| 오프라인 | 캐시 데이터 표시 + 동기화 대기 배지 |

## 6. 데이터

- 지문: 향후 `users/{uid}/utv/current` 캐시
- 원장: `users/{uid}/trips`
- 랭킹: `users/{uid}/ranking/current`
- 랭킹 저장 이벤트: `ranking_adjusted`
- 지문 변화: `utv_recomputed(trigger=rank_edit|evaluated)`

현재 UTV 캐시를 만들기 전에는 지문 UI를 온보딩 계산 결과 또는 앱 내 원장 재생 결과로
구성해야 합니다.

## 7. 완료 조건

- 홈에서 지문·추천 1장·현재 최우선 행동을 한 화면에서 확인 가능
- 랭킹 조정 후 저장과 지문 변화 피드백 완료
- 낮은 신뢰도와 매칭 미사용 축을 숨기지 않고 표시
