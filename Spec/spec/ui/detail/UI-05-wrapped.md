# UI-5. Wrapped 취향 이미지

## 1. 목적

한 해의 여행 기록·랭킹·지문·하루 한 장을 짧은 카드 시퀀스로 요약하고, 저장·공유 가능한
이미지를 만듭니다. MVP는 **Wrapped 라이트**이며 별도의 긴 스토리 편집기는 만들지 않습니다.

근거: [3.0 스펙 6·9절](../../../docs/product/Travel_Fingerprint_3.0_Spec.md)

연간 Wrapped는 6장 카드로 확정합니다. Spotify Wrapped가 최근 수년간 11월 말~12월 초에
공개된 패턴(2025년 12월 3일 공개)을 참고하되, 우리 서비스 노출 기간은 운영이 단순한
**12월 15일~다음 해 1월 15일**로 고정합니다.

## 2. 진입 조건

- 12월 15일~다음 해 1월 15일에만 홈의 `올해의 여행 지문` 카드 노출
- 같은 기간에만 연말 알림 또는 앱 내 배너 노출
- 최소 1개 이상의 해당 연도 여행
- 사진이 없어도 생성 가능, 사진이 있으면 하루 한 장 우선 사용
- 노출 기간 밖에는 홈과 앱 내 과거 Wrapped 목록을 숨김
- 개별 여행 공유는 연간 Wrapped와 별개로 여행 상세에서 연중 제공

12월에 새 여행이 추가되면 1월 15일까지 `업데이트해서 다시 보기`를 제공합니다. 12월 31일
이전에는 `올해 지금까지`, 1월 1일부터는 확정된 연도 표현을 사용합니다.

## 3. 메인 UI

### UI-5A. 시작

- 연도와 제목: `2026 여행 지문`
- 해당 연도의 여행 국가 수·여행 수
- 주 CTA: `내 Wrapped 보기`
- 보조 CTA: `나중에`

### UI-5B. 카드 시퀀스

상단 진행 바, 화면 탭으로 다음 카드, 왼쪽 탭으로 이전 카드. 자동 재생은 사용하더라도
일시정지 가능해야 합니다.

#### W1. 올해의 이동

- 세계 지도와 방문 국가 핀
- `올해 4번의 여행으로 6개 나라를 만났어요`

#### W2. 올해의 1위 여행

- 랭킹 보드 1위 여행
- 대표 사진
- `올해 가장 좋았던 여행`
- 다국가 여행이면 여행 단위로 표시

#### W3. 가장 강한 취향

- 지문에서 가장 선명하고 신뢰도 높은 축
- `올해는 대자연 쪽으로 더 가까워졌어요`
- 추천 매칭 미사용 축이면 “추천 근거”라고 표현하지 않음

#### W4. 올해의 태그

- 가장 자주 고른 긍정 태그 2~3개
- 부정 태그는 공유 카드의 주인공으로 쓰지 않고 개인 회고 보조로만 표시

#### W5. 여행 사진 모자이크

- 하루 한 장의 수동 선택 사진 우선
- 부족하면 자동 폴백 사진
- 사진이 없으면 지도·지문 그래픽으로 대체

#### W6. 최종 공유 카드

- 연도, 여행 지문, 1위 여행, 대표 태그
- 개인 식별 정보와 정확한 날짜는 기본 공유 이미지에서 제외
- CTA: `이미지 저장`, `공유하기`
- 보조 CTA: `처음부터 보기`

## 4. 서브 UI

### UI-5C. 공유 미리보기

- 세로 9:16 기본
- 앱 워터마크는 작게
- 사진 공개 범위 확인
- `여행지 이름 표시` 토글
- 최종 CTA: `공유`

### UI-5D. 사진 교체

- 최종 카드에서 대표 사진만 교체 가능
- 후보: 해당 연도 하루 한 장 사진
- 새로운 사진 업로드/편집은 MVP 범위 밖

### UI-5E. 기간 내 다시 보기

- 현재 시즌에 생성한 카드 다시 보기
- 해당 연도의 원장이 바뀌면 `업데이트해서 다시 보기`
- 1월 16일부터 앱 내 진입은 닫고, 유저가 저장한 이미지에는 영향을 주지 않음

## 5. 상태와 예외

| 상태 | 처리 |
|---|---|
| 여행 0개 | 생성 진입 숨김, 여행 등록 CTA |
| 노출 기간 밖 | 홈·배너·앱 내 다시 보기 진입 숨김 |
| 여행 1개 | 비교 표현 없이 한 여행 중심 카드 |
| 사진 없음 | 지문·지도 기반 그래픽 |
| 지문 신뢰도 낮음 | `올해의 첫인상`으로 표현 |
| 조건부축만 가장 크게 변함 | 변화는 표시하되 추천에 사용됐다고 말하지 않음 |
| 공유 권한 실패 | 이미지 저장 또는 시스템 설정 안내 |

## 6. 데이터와 이벤트

- 여행/랭킹: `users/{uid}/trips`, `ranking/current`
- 사진: `users/{uid}/dailyPhotos`
- 지문: UTV 캐시 또는 원장 재생 결과
- 기본 이벤트 제안:
  - `wrapped_opened`
  - `wrapped_completed`
  - `wrapped_image_saved`
  - `wrapped_shared { destination_count, has_photo }`

이 이벤트 이름은 [KPI 문서](../../analytics/05-kpi-and-events.md)의 3.0 기준과 일치합니다.

## 7. 완료 조건

- 데이터가 적어도 깨지지 않는 카드 생성
- 개인용 회고와 공유용 이미지의 정보 노출 구분
- 저장 또는 시스템 공유 시트 호출 완료
