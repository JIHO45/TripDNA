# UI-6. 과거·예정·현재 여행 등록

## 1. 목적

여행의 사실 정보만 원장에 저장하고, 종료 평가와 하루 한 장 알림이 작동할 최소 배관을
만듭니다. 여행 등록 시 취향·무드 질문은 하지 않습니다.

근거: [3.0 스펙 2.1·2.5·2.6절](../../../docs/product/Travel_Fingerprint_3.0_Spec.md),
[Firestore 원장](../../data/10-firestore-schema.md)

## 2. 메인 UI

### UI-6A. 내 여행 목록

세 구역 또는 세그먼트:

1. **현재 여행**
2. **예정된 여행**
3. **지난 여행**

각 여행 카드:

- 국가 또는 다국가 여행명
- 도시
- 기간
- 상태 배지
- 대표 사진(있는 경우)
- 평가 대기 여부

우측 하단 주 CTA: `+ 여행 등록`

## 3. 등록 방식 선택

### UI-6B. 등록 시작

- `지금 또는 예정된 여행`
- `과거 여행`
- 과거 여행인 경우:
  - `사진첩에서 찾기`
  - `직접 입력`

온보딩에서 사진첩 권한이 이미 있으면 권한 요청 없이 스캔 결과로 연결합니다.

## 4. 여행 등록 폼

### UI-6C-1 구간 입력

- 국가 검색(필수)
- 도시 검색/직접 입력(선택, 복수)
- 시작일·종료일(필수)
- `나라 추가`로 다국가 구간 추가
- 구간 카드는 드래그로 순서 변경
- 같은 날짜 중복이나 종료일<시작일은 인라인 오류

프로필 미확정 국가도 검색·등록 가능하며 `추천 분석은 준비 중` 안내만 붙입니다.

### UI-6C-2 동행

- 질문: `누구와 함께하나요?`
- 혼자 / 커플 / 가족 / 친구
- 원탭

### UI-6C-3 여행 성격

- 질문: `이번 이동은 어떤 여행인가요?`
- 여행(기본) / 출장·행사 등 의무
- 설명: 의무 여행은 취향 반영이 낮아짐

### UI-6C-4 확인

- 국가·도시·기간·동행·성격 요약
- 주 CTA:
  - 미래/현재: `여행 등록`
  - 과거: `과거 여행 저장`
- 보조 CTA: `수정`

### UI-6C-5 알림 프라이밍

여행 등록 완료 직후:

- `여행이 끝나면 30초 평가를 알려드릴게요`
- 주 CTA: `알림 받기`
- 보조 CTA: `나중에`
- 시스템 알림 권한은 CTA 후 요청

## 5. 과거 여행 빠른 등록

### UI-6D. 사진 스캔 결과

- 지도 핀 또는 여행 카드 목록
- 위치·날짜가 이어진 사진을 여행 단위로 묶고 국가·시기 자동 완성
- 한 여행 안에서 국경을 넘은 사진 군집은 `legs`가 여러 개인 다국가 여행으로 제안
- `여행 합치기` / `여행 나누기` / `나라 추가`로 자동 군집 수정
- 여행별 대표 사진 1장을 자동 제안하고 같은 여행의 사진 중 교체 가능
- 만족도 1~5만 받음
- 2개째부터 서열 비교
- `이 여행 아니에요`
- 상세 흐름은 UI-1B와 동일한 컴포넌트 재사용

### UI-6E. 과거 여행 수동 등록

- 국가, 대략적 시기, 만족도
- 선택: 긍정 관심사 태그 최대 3개
- 1화면 카드형 입력
- 저장 후 `여행 하나 더` / `완료`

온보딩이 아닌 일반 사용 중 과거 여행을 추가하면 `evalSource=manual_backfill`로 저장합니다.

## 6. 여행 상세·상태 전환

### UI-6F. 예정 여행 상세

- 일정, 구간, 동행, 성격
- CTA: `여행 시작`
- 보조: 알림 설정

### UI-6G. 현재 여행 상세

- 현재 일차
- 오늘 하루 한 장 상태
- CTA: `오늘의 한 장 고르기`
- 보조: `여행 종료`

### UI-6H. 지난 여행 상세

- 평가 완료: 결과와 태그 표시
- 평가 미완료: `30초 평가하기`
- 랭킹 위치
- 여행 대표 사진
- 세로형 여행 카드 `공유하기`
- 대표 사진 변경: 하루 한 장 사진을 우선 제안하고 사진첩에서도 선택 가능

## 7. 자동 여행 감지 넛지

- 알림: `파리에 도착하셨군요! 여행 기록을 시작할까요?`
- 탭 → 국가·도착일이 미리 채워진 UI-6C
- 이미 등록된 여행과 겹치면 알림 없음
- 감지 자체와 위치 권한 프라이밍 화면은 별도 설정에서 관리

## 8. 상태와 예외

| 상태 | 처리 |
|---|---|
| 국가 프로필 미확정 | 등록 허용, UTV 반영 보류 안내 |
| 다국가 | 구간 추가, 평가 때 베스트 국가·태그 귀속 활성화 |
| 종료일 없음 | 현재 여행 등록 시 추정 종료일 요청; 평가 알림 배관 때문에 필수 |
| 권한 거부 | 수동 등록 유지 |
| 오프라인 | 로컬 캐시에 기록 후 동기화 대기 표시 |
| 중복 여행 후보 | 자동 병합 금지, 확인 후 처리 |

## 9. 데이터

- `users/{uid}/trips/{tripId}`
- 주요 필드: `legs`, `companion`, `purpose`, `status`, `coverPhotoStoragePath`, `createdAt`
- 이벤트: `trip_started`
- 앱은 문서 전체를 교체하지 않고 상태에 따라 필요한 필드만 업데이트

## 10. 완료 조건

- 최소 한 구간, 기간, 동행, 성격이 원장에 저장됨
- 여행 상태에 맞는 홈 카드 생성
- 종료일 기반 평가 알림 배관 준비
