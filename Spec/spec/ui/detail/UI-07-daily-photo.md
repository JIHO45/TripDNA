# UI-7. 여행지 대표 사진 — 하루 한 장

## 1. 목적

여행 중 매일 대표 사진 한 장을 골라 종료 평가의 기억 단서와 Wrapped 재료를 남깁니다.
이 입력은 **취향 신호가 아니며 UTV·국가 프로필에 반영하지 않습니다.**

근거: [3.0 스펙 2.6절](../../../docs/product/Travel_Fingerprint_3.0_Spec.md)

## 2. 진입

- 여행 중 하루 끝 알림
- 홈의 현재 여행 카드
- 여행 상세의 `오늘의 한 장 고르기`
- 알림은 놓친 날을 추궁하지 않음

## 3. 메인 UI

### UI-7A. 오늘의 한 장

- 상단: 여행명과 `3일차`
- 제목: `오늘을 한 장으로 남긴다면?`
- 오늘 촬영한 사진 그리드
- 날짜가 다른 사진은 기본 후보에서 제외
- 한 장 선택 시 큰 미리보기
- 주 CTA: `이 사진으로 남기기`
- 보조 CTA: `오늘은 건너뛰기`

촬영 버튼이 아니라 사진첩에서 **고르는 기능**입니다.

### UI-7B. 사진 접근 프라이밍

권한이 없는 경우:

- `오늘 찍은 사진에서 한 장만 고를 수 있도록 사진 접근이 필요해요`
- 데이터 경계 안내
- CTA 후 시스템 사진 권한
- 거부 시 기능을 막지 않고 건너뛰기

## 4. 서브 UI

### UI-7C. 사진 선택 미리보기

- 큰 이미지
- `다른 사진 고르기`
- 주 CTA: `확정`
- 저장 전에만 교체 가능

첫 여행에서 첫 하루 한 장을 확정한 직후 한 번만 자동 후보 동의를 묻습니다.

- 제목: `놓친 날도 사진을 골라둘까요?`
- 설명: `건너뛴 날에는 그날 찍은 사진 중 한 장을 자동 후보로 저장해 회고 때 보여드려요`
- 선택: `자동으로 골라두기` / `직접 고른 사진만 사용`
- 선택은 설정에서 언제든 변경

### UI-7D. 하루 반응

사진 확정 후 선택형 후속:

- 질문: `오늘은 어땠나요?`
- 좋았어 / 그럭저럭 / 별로
- `건너뛰기`
- 축·태그 질문 금지

### UI-7E. 저장 완료

- 사진과 날짜
- 문구: `오늘의 한 장을 남겼어요`
- CTA: `여행으로 돌아가기`
- 스트릭, 배지, 연속 기록 카운터 없음

### UI-7F. 여행 사진 타임라인

여행 상세에서:

- 날짜별 대표 사진 가로 타임라인
- 수동 선택과 자동 후보를 시각적으로 강하게 차별하지 않음
- 미선택 날짜는 `자동으로 골라둘게요` 상태
- 죄책감을 유발하는 빈칸/경고 금지

## 5. 자동 후보 폴백

- 유저가 사전 동의한 경우에만 건너뛴 날의 EXIF 날짜 기준 후보를 자동 선정
- 동의하지 않으면 미선택 날짜는 비워 두며 반복해서 묻지 않음
- 자동 선택은 앱이 실제 사진 자산 접근 권한을 가진 범위에서만 수행
- 종료 평가 때 수동+자동 후보를 날짜순으로 보여줌
- 종료 후 여행 대표 사진은 하루 한 장의 수동 선택 사진을 우선 제안하되, 다른 하루 한 장이나
  사진첩 사진으로 교체 가능

## 6. 상태와 예외

| 상태 | 처리 |
|---|---|
| 오늘 사진 0장 | `오늘 찍은 사진이 없어요` + 건너뛰기 |
| 제한된 사진 권한 | 허용된 사진만 표시, 설정 안내는 사용자가 요청할 때만 |
| 권한 거부 | 건너뛰기, 반복 권한 요청 금지 |
| 중복 선택 | 같은 사진을 다른 날짜에 중복 저장하지 않도록 경고 |
| 오프라인 | 로컬 캐시 저장 후 동기화 대기 |
| 여행 구간 변경일 | 사진 EXIF와 여행 구간 날짜로 귀속, UI에는 해당 국가 표시 |

## 7. 데이터

- `users/{uid}/dailyPhotos/{photoId}`
- 필드: `tripId`, `tripDayIndex`, `storagePath`, `selection`, `dayReaction`, `createdAt`
- 자동 후보 동의: `users/{uid}.dailyPhotoAutoFallbackConsent`
- 이벤트: `daily_photo_selected`
- 사진 바이너리는 Firestore 문서에 저장하지 않음
- 확정된 수동 사진과 동의된 자동 후보는 Firebase Storage의 유저 전용 경로에 업로드
- 다른 iPhone·iPad·Mac에서도 같은 계정으로 사진 조회 가능
- 업로드 전에 EXIF 위치 메타데이터를 제거하고 화면용 리사이즈본만 저장
- 원본은 업로드하지 않으며 Storage Rules로 본인 경로만 읽기·쓰기 허용

## 8. 금지 사항

- 취향 축 질문
- 관심사/부정 태그
- 스트릭·배지·미선택 경고
- 하루 한 장 반응을 MVP 추천 점수에 반영
- 원본 사진 위치 정보를 서버에 전송

## 9. 완료 조건

- 하루 대표 사진 1장과 선택 반응(선택)이 기록됨
- 종료 평가 회고 타임라인에서 사용 가능
- UTV 입력 스트림과 완전히 분리
