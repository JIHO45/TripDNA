## 해석

- 현재 지침에서 두 모델의 차이는 지난번보다 작다. 인용 대응 실패는 비슷해졌고(5 대 6), 언어 정책은 둘 다 정답 사례를 모두 맞혔다.
- 남은 Haiku의 약점은 두 가지다. (1) 검색 원문 영어를 본문에 그대로 붙이는 답이 26건 중 3건(H02·H05·H07 각 1회). Sonnet은 0건. (2) 실제 오류 1건(H08: 일요일 오전에 야나기바시 시장을 권함. 다른 답의 검색 결과로는 일요일·공휴일 휴무).
- 지난번 Haiku의 실제 오류(H07 죽 가게를 카오만가이 가게로)는 이번 Haiku 2회에서 재현되지 않았다. 한 답은 "카오만가이와 족(쌀죽)"으로 둘을 나눠 썼다.
- 인용 대응 실패는 두 모델 공통이다. 대부분 숫자·평가에 다른 항목의 원문이 붙거나 원문이 제목에서 잘린 경우다. 앱은 인용 원문을 보여 주지 않고 링크만 보여 주므로, 사용자가 겪는 일은 "링크가 문장과 맞지 않음"이다.
- Haiku는 요약을 대화 언어와 상관없이 영어로 쓴다(Sonnet은 한국어). 요약은 다음 호출에만 쓰이므로 화면 문제는 아니다. 자동 검사의 한국어 키워드 표시 4건은 이 때문에 생긴 오탐이었고, 원문으로는 땅콩 금지·5시간 제한을 모두 필수 조건으로 남겼다. 다만 Haiku 요약 1건(S02 r1)에 "料憊は싫어요" 같은 깨진 글자가 있었다.
- 비용은 지난번과 같다. Sonnet이 답당 약 3.1배다.
