# 고정 자료 모델 비교: 판정 (2026-11-05, 2차 정리)

용도: 당시 지침(언어 정책·요약 변경 전)의 진단 자료다. 최종 모델 선택의 근거로 쓰지 않는다.

판정자: Claude(이 세션). **Joe의 사람 검수 전**이라 모든 집계는 잠정치다. 기준은 `cases.json`과 `evidence.json`의 원문이다.
조건: web_search 없이 같은 문서(인용 켬)를 Haiku 5.5와 Sonnet 5.5에 주었다. 사례당 3회. 사례 4개는 이전 Haiku 실행에서 문제가 나온 것만 골랐으므로 Haiku에 불리하게 치우친 표본이다.

분류
- **실제 오류**: 자료와 반대이거나 기준을 바꿈.
- **근거 부족**: 자료에 없는 것을 단정하거나, 엇갈리거나 모호한 자료를 한쪽으로 단정함.
- **검토 필요**: 오류로 확정할 수 없어 사람이 봐야 함. 오류 수에 넣지 않는다.
- **언어**: 외국어 문장을 그대로 붙임(사실 판정과 별도).

1차 정리(같은 날)에서 바꾼 판정: ¥800. 원문 문장("mentaiko tamagoyaki ... paired with a bowl of tonkotsu ramen for only about ¥800")은 조합 가격으로 읽히지만, 같은 자료의 다른 가게 가격(계란말이 단품 ¥900~950, 라멘 ¥700)과 맞지 않아 원문 자체가 모호하다. 그래서 Haiku r2·r3의 "라멘 한 그릇은 약 800엔"을 실제 오류에서 **근거 부족**(모호한 원문을 원문 문장과 다른 쪽으로 단정)으로 낮췄다. Sonnet의 "계란말이와 라멘을 약 ¥800에"는 원문 문장에 가깝지만 같은 모호함을 단정했으므로 **검토 필요**로 둔다. 원문을 "~라고 나와 있다"로 옮긴 Haiku r1도 검토 필요다.

## 자동 판정과의 차이

- 검사기 집계는 2차 정리에서 종류별로 나눴다. 이전에는 검토 필요까지 "사실 문제"로 세어 Sonnet H08 세 답이 오류처럼 보였다.
- 첫 규칙(1차)은 사람 판정의 실제 오류·근거 부족 13건 중 1건만 잡았다. 누락은 야나기바시 4건(엇갈림 표시 조건의 "확인"이 너무 넓음), H05 haiku r1·r3, H07 haiku r1, ¥800 두 건(검토 필요로만 잡힘). 오탐은 H11 sonnet r3("확정되기 전"), H08 haiku r1(일반 "타마고야키"), H07 sonnet r2("주의사항"의 "의사").
- 규칙을 고친 뒤 같은 24건의 자동 집계(검토 필요 제외): Haiku 실제 오류 3·근거 부족 4, Sonnet 근거 부족 1. 사람 판정과 다른 곳: H08 haiku r1 명란 오탐(실제 오류로 잡음), H08 haiku r2·r3 ¥800(근거 부족이지만 검토 필요로만), H07 haiku r1(누락). 같은 답에 맞춰 고친 결과라 성능 증거가 아니다.

## 해석과 한계

- 같은 문서를 줬을 때 Sonnet 5.5가 더 나을 가능성이 보인다. 확정은 Joe의 검수 뒤에 한다.
