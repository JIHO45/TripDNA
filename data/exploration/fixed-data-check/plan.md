# 검색 없는 고정 자료 추천 확인 — 계획

2026-10-12 작성. 사례 13개를 [`run1/cases.json`](run1/cases.json)에 고정했다. 이 문서는 실행 1의 계획이며 실행 2는 [`run2/plan.md`](run2/plan.md)에 있다. 같은 날 13건을 실행했다([결과](result.md)). 실행: `scripts/run_fixed_data_check.py`.

## 묻는 것

[컨셉 기반 추천](../../../docs/recommendation/README.md#2026-10-08-결정-컨셉-기반-추천)은 검색을 기본으로 끄고 고정 자료로 판정한다고 정했지만 이 구성은 실험한 적이 없다. 이전 [칩 대 LLM 비교](../chips-vs-llm/result.md)는 검색을 켠 결과다.

1. 등급·시즌·핵심 경험만 받은 LLM이 주 컨셉 2등급 미만 도시와 시즌 밖 세부를 피하는가
2. 자유문장의 조건을 검색 없이 지키는가
3. LLM이 놓친 것을 코드 검사가 잡는가

## 구성

- 자료: [`city-draft/draft.json`](../city-draft/draft.json)의 20곳(호출 시점의 사본은 `run1/draft.json`). 첫 호출 뒤에는 고치지 않는다. 고치면 새 실행이다.
- 모델: Gemini Flash, 검색 없음. 한 방식만 돌린다. 방식 비교가 아니라 이 구성이 쓸 만한지 보는 것이다.
- 입력: 주 컨셉(필요하면 세부), 부 컨셉, 시기, 자유문장, 도시 표(큰 컨셉·세부 등급, 시즌, 시즌 미확인, 핵심 경험). 현지인 만나기는 선택지에서 뺀다.
- 출력: 순위가 있는 도시 ID, 도시별 맞는 이유와 유의점

## 사례

고정한 13개의 종류다. 사례별 기대와 사람이 볼 점은 `run1/cases.json`에 있다.

| 종류 | 예 | 기대 |
|---|---|---|
| 시즌 밖 | 1월, 주 컨셉 액티비티·겨울 스포츠 | 퀸스타운을 내지 않거나 시즌 밖임을 밝힌다. 밴쿠버는 가능 |
| 시즌 안 | 7월, 같은 입력 | 퀸스타운 |
| 시즌 밖 | 6월, 이벤트·축제 | 교토·멕시코시티·델리를 축제 근거로 내지 않는다 |
| 한 대회 | 3월, 이벤트·스포츠 직관 | 싱가포르를 F1 근거로 내지 않는다 |
| 시즌 미확인 | 7월, 이벤트·스포츠 직관 | 이스탄불을 내면 확인이 필요하다고 밝힌다 |
| 등급 미달 | 주 컨셉 자연 | 도쿄·방콕을 내지 않는다 |
| 근교 | 주 컨셉 휴양·온천 | 도쿄를 하코네 근거로 올리는지 본다(자료에는 근교로만 적혀 있다) |
| 자료에 있는 조건 | 자유문장으로 시기·근교·특정 경험을 말한다 | 자료대로 답한다 |
| 자료에 없는 조건 | 자유문장으로 비행시간, 고도, 비자, 해파리 철을 말한다 | 자료로 확인할 수 없다고 밝힌다. 단정하면 실패 |

이전 실험의 사례를 그대로 가져오지 않는다. 이전 사례에는 지금 자료에 없는 조건(비행시간, 고도, 비자, 해파리)이 있어 같은 판정 기준을 쓰면 자료 부족과 LLM의 자료 무시가 섞인다. 가져올 때는 조건이 자료에 있는지부터 표시한다. 푸껫 ID는 이전 사례의 `th-phuket`을 `th-phuket-island`로 맞춘다.

## 기록

호출마다 다음을 따로 남긴다.

- LLM 원출력
- 코드 검사 뒤 결과: 허용 ID, 주 컨셉 2등급 이상, 시즌(시기가 주어졌을 때 시즌 밖 세부를 빼고 다시 계산)
- 실패의 분류
  - 자료 오류: 자료가 틀려서 생긴 실패
  - 자료에 없음: 조건을 판정할 자료가 없는 경우. LLM이 확인할 수 없다고 밝혔는지를 본다
  - LLM 무시: 자료가 맞는데 LLM이 따르지 않은 실패
  - 코드가 잡음: LLM은 틀렸지만 코드 검사가 걸러 낸 경우
  - 코드가 못 잡음: 코드 검사를 통과한 실패

## 한계

- 자료 20곳은 사람 검수 전이다. 자료가 틀려서 생긴 실패와 구성의 실패를 가르는 데 한계가 있다.
- 사례와 판정을 AI가 만든다. 사람 확인 전에는 잠정이다.
- 검색을 쓰지 않으므로 [Gemini 그라운딩 조항](../README.md#저장소에-올리지-않는-기록-2026-10-12)의 대상이 아닌 것으로 보이지만 약관을 다시 확인하지 않았다. 확인 전까지 응답 원본(`responses.jsonl`)은 `.gitignore`에 두고 저장소에 올리지 않는다.
- 코드 검사는 허용 ID, 주 컨셉 2등급 이상, 시즌만 본다. 유의점 문장의 내용, 자료 밖 지식의 표시 여부, 근교를 근거로 썼는지는 사람이 읽어야 한다.
- 입력에 도시 20곳의 자료 전체(약 4만 자)를 넣는다. 100곳이면 다섯 배가 되므로 이 실험은 입력 크기 문제를 다루지 않는다.
