# 지난 여행 메모 비교 — 실행 2 계획

2026-10-12 작성. 같은 날 92건을 실행했다([결과](result.md)). 실행: `scripts/run_memo_check.py`(기본이 실행 2). [실행 1의 결과](../result.md)에 이어지는 실행이다.

## 왜 하는가

실행 1에서 도시 자료 전체를 보내는 방식(T)은 요청과 메모의 범위를 가장 잘 지켰지만 목록이 자주 어색했고, 입력이 호출당 약 9,000토큰이었다. 자료를 다 뺀 방식(P)은 입력이 12분의 1이었지만 요청을 붙잡는 힘과 자료에만 있는 연결(온천, 하맘)을 잃었다.

사용자가 중간 방식을 정했다: **후보마다 강한 경험의 이름만 보낸다.**

## 새 방식 N

- 후보는 코드가 정한다. 주 컨셉이 "일부러 시간을 낼 만함" 이상이고 다녀오지 않은 도시다.
- 후보마다 이번 주 컨셉의 단계와, 모든 컨셉에 걸쳐 위 두 단계("여행지를 선택할 만함", "일부러 시간을 낼 만함")에 든 세부의 이름을 보낸다. 핵심 경험 문장과 아래 두 단계는 보내지 않는다. 시즌은 보낸다.
- 주 컨셉에 해당하는 부분만 자르지 않는다. 사용자가 글로 쓴 것이 다른 컨셉에 적혀 있을 수 있기 때문이다(실행 1에서 케언스의 바다는 휴양이 아니라 액티비티에 있었다).
- 기준 순서를 따로 주지 않는다. 주 컨셉의 단계가 도시마다 적혀 있고, 같은 단계는 동점이며 맞는 정도로 순서를 정하라고 지침에 적었다.
- 개인화 규칙은 T와 같은 문장이다. 이유 문장에 순위를 조정한 과정을 적지 않게 한 것만 다르다(실행 1에서 검수자가 감점한 부분).

도시 등급을 -1 같은 감점으로 넓히지 않는다(사용자 결정). 치안, 날씨, 붐빔 같은 정보는 이 자료에 없다.

## 실행 1과 다른 점

| 항목 | 실행 1 | 실행 2 |
|---|---|---|
| 방식 | A, B, T, 나중에 P | A, B, T, P, N을 한 번에 |
| 자료 | 이전 뜻의 등급(숫자) | 등급을 이름으로 바꾼 [자료](draft.json). 경계 칸 5개가 바뀌었다 |
| 사례 | 9개 | 같은 9개 + 새 5개(R5~R9) |
| 메모 없는 경우 | 두 번씩 | 한 번씩 |

- 기존 9개도 전부 다시 돌린다. 실행 1은 사례마다 한 번뿐이었으므로 같은 사례의 결과가 얼마나 달라지는지를 함께 본다.
- 새 5개는 실행 1의 결과를 본 뒤에 만들었지만 지침은 이 사례들을 보고 고치지 않았다: 문화·역사(골목은 좋고 줄은 싫었다), 액티비티(카약은 좋고 번지는 무서웠다), 도시(너무 커서 지쳤다), 미식(메모 두 건), 자연(지난 여행은 걷기가 좋았고 이번 요청은 걷지 않는 풍경).
- 자료에서 바뀐 5칸: 교토의 료칸과 술이 한 단계 위로, 교토·멕시코시티의 축제와 싱가포르의 스포츠 직관이 맨 위로. 교토가 휴양 후보가 된다.

호출은 92건이다: A 9, B 14, T·P·N 각 23.

## 보는 것

1. N이 T만큼 요청과 메모의 범위를 지키는가(R2-M3, R1-M3, R3-M1, R9)
2. N이 T가 어색했던 목록을 피하는가(R1-M1의 방콕, R2-M2의 케언스, R3의 5위)
3. N이 자료에만 있는 연결을 유지하는가(R2-M1의 온천과 하맘)
4. 입력 크기. 호출 전 사용자 입력의 평균 글자 수는 T 약 12,400자, N 약 2,800자, B 약 500자, P 약 400자다. N은 T의 4분의 1에 못 미친다. 토큰 수는 호출 뒤에 잰다.
5. 같은 사례를 다시 돌렸을 때 실행 1과 얼마나 다른가

## 평가

`--sheet`가 B·T·P·N을 가린 시트(`sheet4-on.md`)를 만든다. 사례 14개에 목록이 넷씩이다. 1부(후보만)를 먼저 보고 2부(이유 문장)를 본다.

## 한계

- 검수자는 기존 9개 사례의 B·T·P 목록을 이미 봤다. 새 5개만 처음 보는 사례다.
- N은 도시 자료의 형식과 문장 규칙이 함께 바뀌었다. T와 N의 차이를 형식 하나의 효과로 읽을 수 없다.
- 자료는 새 뜻으로 전부 다시 매긴 것이 아니다. 미리 확인한 경계 칸 5개만 바꿨다.
- 여행자는 가상 인물이고 메모를 작성자가 지었다. 사례마다 한 번 돌린다.
- 세부의 이름만으로는 알 수 없는 것이 있다. 예를 들어 도시의 크기(R7)와 붐비는 정도(R1-M1)는 자료에 없어 LLM의 지식에 기댄다.
- 검색을 켠 응답 원본과 시트는 저장소에 올리지 않는다.
