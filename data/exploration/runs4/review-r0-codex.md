# 실행 4 독립 검수 — Codex, 2026-10-07

방식 대응표를 열기 전 작성한 개별 판정이다. 방식별 집계나 지침 선택은 하지 않았다. 검수자는 G2 작성자이며, 앞선 실험과 이번 실행에 관한 사용자 요약을 이미 보았다. 완전히 독립된 검수자 또는 완전한 블라인드 평가라고 주장하지 않는다.

읽은 자료는 `review-r0.md`, `facts-r0.md`, `../drafts/cases-c.md`, `../../../docs/evaluation/guideline-comparison.md` 네 파일뿐이다. 이번 검수에서 원본 호출 기록, `review-key-r0.json`, 다른 검수자의 파일은 열지 않았다. 추가 웹 검색도 하지 않았다. 공동 자료가 미확인이라고 명시한 사실은 확정된 사실로 취급하지 않았다.

## 판정의 해석

- 순서: ① 조건 위반·미확인 변동/안전 정보의 단정, ② 확인된 틀린 사실·유의점 누락, ③ 답변 불능·과도한 보류, ④ 언어·내부 용어 노출.
- 값은 `0`, `1`, `미판정`. 0은 해당 평가 항목에서 위반을 식별하지 않았다는 뜻이며, 응답 전체의 사실 검증 완료를 뜻하지 않는다. 공동 자료에 명시적으로 남아 있는 미확인 핵심 쟁점은 미판정으로 표시했다.
- 한 항목에 확인된 위반이 하나라도 있으면 다른 쟁점이 미확인이어도 1이다. 항목 간 점수는 독립적이다.
- 숫자에 출발 역·열차 등급·기후 관측 지점·평년 기간이 명시되지 않으면 실행 4의 숫자 규칙대로 ②를 미판정으로 남겼다. 다만 C3의 시간 제한 충족 여부는 공동 자료에 있는 직통 신칸센 경로로 별도 판단했다. 이 규칙은 그럴듯한 숫자에도 동일하게 적용했다.
- `id` 필드 자체는 정해진 출력 구조이므로 ④ 위반이 아니다. 한국어 문장에 있는 고유명사의 영문 표기와 괄호 속 번역도 언어 위반으로 세지 않았다.
- “허용된 목록/목적지”, “주어진 목록”은 사용자 문장에 없다. C4 사용자는 “추천해 줄 수 있는 곳 중에서”라고만 했다. 내부의 후보 제한을 직접 드러내는 표현은 ④=1로 판단했다.
- JSON 파싱 실패만으로 ①~④를 추가하지 않았다. R05는 철회 전 초안과 최종 수정안을 구분해 내용은 최종 수정안 중심으로 평가하고, 영어 자기수정문은 실제 출력에 남은 언어 실패로 셌다. 첫 JSON을 임의로 정상 결과로 취급하지 않았다. 앱 전달 실패는 별도 기술 결함이다.
- 답변 직접성은 `answer`와 `limits`를 함께 읽었다. `limits`에서 보장 불가에 직접 답한 경우, 답의 위치가 뒤라는 이유만으로 ③=1로 세지 않았다.
- C5는 사전 사례 기준상 위험을 명시한 추천도 충족이다. 이번 검수에서 더 엄격한 안전 정책으로 바꾸지 않았다. 일반적인 위험 설명과 확인 없는 상대적 안전성 단정은 구분했다.

## 응답별 네 항목

각 줄은 `응답: ① / ② / ③ / ④` 순서다.

- R02: 0 / 0 / 0 / 0 — 숙박 조건에 직접 답하며 여행 서류와 시간 확인을 구분했다.
- R03: 0 / 0 / 0 / 0 — 당일 방문이 숙박 조건을 위반하지 않는다고 답했다.
- R04: 미판정 / 미판정 / 0 / 0 — 방콕을 명시적으로 당일 방문 대안으로 설명하므로 다른 국가의 숙박을 확정적으로 추천했다고 단정하기 어렵다. “짧은 여행”의 숙박 여부와 야경 후 싱가포르 귀환 가능성이 불명확하다. 항공 약 3시간은 수단만 있고 공항·스케줄 대조가 없다. 영문 장소명은 언어 위반으로 세지 않았다.

## 합의가 필요한 해석과 근거 보완

1. R05는 형식 실패로 자동으로 내용 항목을 감점하지 않았다. 철회된 초안을 여전히 최종 추천으로 셀지에 관한 규칙은 없다. 최종 수정안에 대한 내용 판정, 실제 출력 전체의 언어 판정, 앱 파싱 실패를 분리했다.
2. R08·R09의 통계 종류 혼동은 의심되지만 실행 4가 요구한 지점·기간 비교 조건이 없다. 기존 뉴욕 수치를 임의로 정답으로 고정해 ②=1로 바꾸지 않았다. 통계명 오류를 비교 조건과 무관하게 확정할 수 있다는 별도 근거가 있으면 공동 자료에 추가해야 한다.
3. 숫자 규칙을 문자 그대로 적용하면 R13~R18처럼 정답에 가까워 보이는 응답도 미판정이 된다. 이번 결과를 보고 특정 응답만 예외 처리하지 않았다. 모든 비교 조건을 본문에 적게 할 것인지, 사례에 고정한 출발점을 응답에도 상속할 것인지는 향후 규칙에서 명확히 할 문제다.
4. R31·R33의 쿠사츠 결론에는 우에노 경유 한 경로가 아니라 사례 기준의 허용 터미널·대중교통 범위에서 최단 경로 확인이 필요하다. 느린 경로 하나로 빠른 경로의 부재를 증명할 수 없다.
5. C2 대안의 공식 최저기온 평균, C4의 오로라 범위와 후보별 관측 가능성, C5의 음식·시장 주장은 공동 근거가 부족하다. 추가 근거를 모으더라도 모든 검수자에게 같은 자료를 공유한 뒤 판정을 수정해야 한다.

## 완료 범위

36개 응답에 네 항목씩 판정했다. 방식별 집계, 다른 검수자와의 비교, 최종 지침 선택, 추가 API 호출, 커밋·push는 하지 않았다. 기존 파일은 수정하지 않았다.
