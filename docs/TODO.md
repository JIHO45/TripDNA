  2026-10-31 무료 한도 서버 계수 구현(배포 전): `cityLLM`이 Firestore `usage/{익명 uid}` 한 문서에 이번 달(UTC) 추천 ID와 질문 수를 세고, 무료 한도(추천 3·질문 3)를 넘으면 429 `{resetAt}`을 돌려준다. 검색 호출은 질문 1회, 검색 없는 호출은 앱이 추천받기마다 만드는 `usageId`별 추천 1회로 센다. Anthropic 호출 실패는 그 호출만 되돌린다. 같은 날 사용자 결정: 앱의 응답 검사 실패(잘림·형식 오류 등)도 횟수를 잃지 않게 한다. 서버가 앱의 실패 보고를 믿지 않도록, 앱이 실패 직후 다음 시도에 같은 ID를 한 번 더 쓰고 서버는 ID 하나를 호출 4번까지 1회로 센다. 이 ID는 기기의 추천 상태(`CityRecommendationState.retryUsageID`, 전체 삭제 대상)에 저장해 화면을 떠나거나 앱을 다시 켜도 다음 추천받기가 이어 쓴다. 다시 추천받지 않으면 차감이 남지만, 그 경우 남은 횟수를 쓰지 않으므로 손해가 없다. 달이 바뀌면 서버가 새 ID로 센다. 계수에 실패하면 호출하지 않고 503. 앱은 한도 초과 시 "이번 달 무료 추천/질문을 다 썼어요.
