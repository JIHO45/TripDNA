# 사실 근거와 출처

상태: 검색 비교 방식과 향후 출력 검증 기준. 검색 도입 여부는 [추천 구조](../README.md#recommendation), 실험별 접근 권한·채점은 [평가](../README.md#evaluation)가 담당한다.

## 검색과 날짜

MD에 출처 작성을 요구하는 것만으로 검색이 실행되지는 않는다. 검색 방식은 실제 도구를 연결하고 조회한 자료를 근거로 답한다. 모델 기억으로 URL·제목·게시일을 만들지 않는다.

추천을 뒤집는 이동·계절·안전·운영 조건을 우선 확인한다. 관광청·기상청·운영사 등 주장에 직접 책임이 있는 공식 출처를 우선하며 근거가 상충하면 적용 지역·기간을 대조하고 해결되지 않은 차이를 남긴다.

- 가격·운행·휴장·안전 공지 등 변동 정보는 최근 1년 내 게시/갱신 자료를 우선한다. 실제 여행 날짜에 적용되는지 별도로 확인한다. 1년 이내라는 이유만으로 현재 유효하다고 승인하지 않는다.
- 기후 평년값·지리·상설 정보는 오래된 공식 자료도 허용한다. 자료가 설명하는 기간·범위와 이후 변경 여부를 구분한다.
- 게시/갱신일 미확인은 그대로 표시한다. 조회일·검색 색인 날짜를 게시일로 대신 쓰지 않는다. 날짜를 확인할 수 없고 변동 정보의 유효성도 검증할 수 없으면 충족을 단정하지 않는다.
- 계절 일반 특성을 당일 날씨·수영 안전·예약 재고 보장으로 바꾸지 않는다.

## 주장과 인용

사용자 사실, 외부 사실, 둘을 연결한 적합성 판단, 미확인을 구분한다. 사실이 섞인 조언도 사실 전제에 근거가 필요하다.
핵심 주장에 출처 번호를 연결하고 하단 Sources에서 제목·URL·게시/갱신일(또는 미확인)·조회일을 확인할 수 있게 한다. 출처의 적용 지역·기간·이동 수단 등 판단에 필요한 한계도 남긴다.

링크가 존재한다고 내용을 검증한 것은 아니다. 위치 근거로 안전·운영 여부를 증명하거나, 편도 시간을 왕복 시간으로 인용하지 않는다. 숫자는 단위·편도/왕복·직항/경유·포함 범위를 보존한다. 계산 책임은 [추천 처리](../README.md#recommendation)를 따른다.

## 확인 불가와 표현

근거를 찾지 못한 핵심 값은 추측해 채우지 않는다. 조건 충족이 미확인이면 이를 표시하고 추천을 조건부로 제시하거나 확인 전 보류한다. 단순히 “확인하세요”라는 유의점을 붙여 이미 위반한 후보를 통과시키지 않는다.
검색 실패·접근 제한·정보 부재를 실제 사실의 부정으로 해석하지 않는다. 확인한 공식 경로가 있으면 연결하고 없으면 링크를 만들지 않는다. 제품에서 제공하는 기능 범위는 [루트 README](../../README.md#범위)를 따른다.

보정되지 않은 매칭 백분율·자체 확신 점수, 집계 없는 “비슷한 사람들이 좋아함”, 근거 없는 인기 순위·국민성·안전·총예산 충족을 표시하지 않는다. 미래 만족이나 새 사람과의 만남 결과도 보장하지 않는다.
출처 표시를 “사실 검증 완료” 배지로 쓰지 않는다. 모델 내부 추론 공개 대신 사용자가 판단할 이유와 근거를 제공한다. 최종 배지 문구·배치는 [화면](../README.md#screens)이 담당한다.
