# 화면별 동작

기준일: 2026-09-30. 상위 기준은 [핵심 설계](../recommendation/architecture.md)와
[루트 README](../../README.md)다. 아래는 목표 동작이며 새 도시·LLM 화면은 미구현이다.

## 화면 목록

- [온보딩](onboarding.md): 방문 기록과 직접 선호를 구분한다.
- [설정·기억·데이터](settings-and-memory.md): 로그인 선택, 기억과 제외 수정, 데이터 삭제.
- [홈·지문·랭킹](home-and-fingerprint.md): 증거에 근거한 요약과 여행 순서.
- [추천](recommendations.md): 도시 선택·피드백·상세 질문.
- [Wrapped·공유](wrapped-and-sharing.md): 확인 가능한 기록의 공유.
- [여행 등록](trip-registration.md): 도시·나라·기간 등 사실 기록.
- [하루 한 장](daily-photo.md): 로컬 사진과 기억 보조.
- [여행 평가](trip-evaluation.md): 좋고 싫었던 이유의 범위를 보존한다.
- [질문 초안](preference-questions.md): 출제 기준과 선택지 의미.

## 공통 흐름

온보딩 → 홈 / 추천 / 여행의 세 탭을 유지한다.
로그인은 진입의 필수 관문이 아니다. 기억·제외·데이터 관리는 설정에서 접근한다.
홈·온보딩·추천 화면은 같은 유효 추천을 재사용해 화면마다 다른 결과가 뜨지 않게 한다.

## 공통 표현과 상태

- 실제 처리에만 로딩을 표시한다. 고정된 분석 대기 시간이나 가짜 작업 단계를 만들지 않는다.
- 선택 입력의 건너뛰기·뒤로가기를 유지한다. 정보가 부족해도 첫 탐색을 막지 않는다.
- 미입력·서로 다른 선호·모두 좋아함·명시적 싫어함을 구분한다.
- 저장한 내용·제외 범위를 보여주고 되돌릴 수 있게 한다.
- 원본 사진/위치 분석의 기기 내 처리와, 확인한 추천 관련 사실의 LLM 전송을 구분해 안내한다.
- 로컬 기록은 오프라인 이용 가능하다. LLM 신규 생성은 불가하며 유효 캐시만 보여준다.
- 오류 시 입력을 보존하고 재시도·수정 경로를 제공한다.
- 긴 글·큰 글꼴·스크롤·VoiceOver를 지원한다. 한 화면에 억지로 고정하지 않는다.

색상·타이포·카드 등은 앱의 기존 공용 컴포넌트를 재사용한다.
예전 다크 테마 생성 프롬프트를 새 디자인의 강제 기준으로 삼지 않는다.
여행·Wrapped·하루 한 장의 기존 기능을 이번 추천 재설계만으로 제거하지 않는다.
