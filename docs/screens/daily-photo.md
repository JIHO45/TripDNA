# 하루 한 장

상태: 기존 로컬 기록 기능 유지. 새 추천용 취향 입력으로 확장하지 않는다.
기준: [루트 README](../../README.md), [데이터 경계](../data/storage-and-privacy.md).

## 기록

현재 여행의 홈 카드·여행 상세·허용한 알림에서 진입한다.
그날 접근 가능한 사진 중 한 장을 선택하고 확인한다.
좋았어/그럭저럭/별로 같은 선택 반응은 개인 회고 보조이며 취향·도시 특성의 정답으로 쓰지 않는다.

사진 접근 권한이 없으면 이유를 설명하고 선택한 경우 요청한다.
거부·제한된 접근·사진 없음은 건너뛰기로 이어진다. 반복 권한 압박을 하지 않는다.
사진 파일은 LocalPhotoStore에 보관한다. Firebase 업로드나 다른 기기 복구를 약속하지 않는다.

## 자동 후보

처음 하루 한 장 확정 뒤 자동 후보 동의를 별도로 받는 기존 흐름을 유지한다.
동의와 자산 접근 권한이 있을 때만 놓친 날짜의 후보를 채운다.
동의하지 않은 경우 날짜를 비워 두고, “자동으로 골라둘게요”라고 표시하지 않는다.
수동 선택 사진을 자동 후보가 덮어쓰지 않게 한다. 동의는 설정에서 변경할 수 있다.

## 회고와 공유

수동 사진을 우선해 회고·여행 대표 사진의 후보로 제안한다.
사진 선택/교체 자체가 좋아하는 경험이나 장기 선호의 증거는 아니다.
기기 내 사진 표시와 외부 공유 이미지의 범위는 다르며 [Wrapped·공유](wrapped-and-sharing.md)를 따른다.

스트릭·미선택 경고·축 질문을 추가하지 않는다.
저장 실패는 입력을 보존해 재시도하고, 로컬 저장을 “동기화 대기”로 표시하지 않는다.
