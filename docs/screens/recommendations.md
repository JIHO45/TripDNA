## 추천 탭

받은 추천이 있으면 그대로 보여준다. 상단에서 “조건 수정”(같은 여행을 계속 알아보기)과 “새 여행 추천”(주 컨셉부터 새로 정하기)을 구분한다. 어떤 조건으로 만든 추천인지 함께 보여준다.
받은 추천이 없거나 새 여행 추천을 누르면 입력 화면을 띄운다. 주 컨셉 하나는 반드시 고른다. 고르면 세부가 펼쳐진다. 세부, “함께 하고 싶은 것” 최대 2개, 시기·기간·예산, 다녀온 곳 포함 여부, 사는 나라 포함 여부(기본 끔, 사는 나라 도시가 목록에 있을 때만 표시), “더 바라는 점이 있나요?” 자유문장은 선택이다. 방문 도시는 기본으로 추천에 포함하며 나라 방문만으로 모든 도시를 제외하지 않는다.
예산·시기·기간은 결과 화면에서도 바꿀 수 있다. 바꿔도 추천 횟수를 쓰지 않는다. 입력하지 않은 조건은 모름으로 둔다.
결과 상단에는 요청을 어떻게 이해했는지의 요약과, 반영한 기억이 있으면 “지난 여행에서 참고한 내용”을 보여준다. 실제로 하지 않는 분석 연출은 넣지 않는다.

카드는 최대 3장이다. 조건에 맞는 도시가 모자라면 그 수만 보여준다. 각 카드에는 도시와 나라, 여기서 즐길 핵심 경험, 이번 요청에 맞는 이유, 안 맞을 수 있는 점과 확인할 조건을 표시한다. 등급 숫자는 보여주지 않는다.
매칭 백분율·고정 탐험 슬롯은 두지 않는다(2026-10-17 변경: 3장 가운데 1장은 조건부 탐색 후보로 고른다. 같은 핵심 선호 충족 수준과 주 컨셉 등급의 대안이 있을 때만 쓰고, 없으면 순서대로 채우므로 고정 슬롯이 아니다. 탐색 카드는 순서만으로 더 잘 맞는다고 읽히지 않게 탐색임을 밝히고 앞의 카드와의 차이를 설명한다. 규칙은 [조건 판정과 순위](../recommendation/README.md#2026-10-17-결정-조건-판정과-순위)의 카드 선택을 따른다). LLM을 쓸 수 없으면 새 추천을 받을 수 없고 그 사실을 알린다.
조건을 검증하지 못했으면 적합하다는 배지를 붙이지 않는다.

2026-10-17 결정: 카드 묶음과 배지를 이렇게 둔다. 근거는 [조건 판정과 순위](../recommendation/README.md#2026-10-17-결정-조건-판정과-순위)다.

| 상황 | 표시 |
|---|---|
| 필수 조건이 없음 | 배지 없음 |
| 필수 조건을 모두 코드가 확인함 | "필수조건 충족". 범위를 밝히며, 단독 "확인됨"은 쓰지 않는다 |
| 필수 조건 가운데 확인하지 못한 것이 있음(추정값뿐 포함) | 기본 추천과 나눈 "추가 확인 필요" 묶음에 둔다. "필수조건 충족"을 붙이지 않고, 확인할 조건 이름을 적는다(예: "확인 필요: 직항 5시간 이내"). 추정값은 "추정"이라고 밝힌다 |
| 필수 조건 위반이 확인됨 | 보여주지 않는다 |
| 선호 조건을 확인하지 못함 | 필수 조건의 배지와 따로 안내한다(예: "축제 일정 확인 필요"). 선호의 미확인이 "필수조건 충족"을 지우지 않는다 |

"추가 확인 필요" 묶음은 기본 추천 카드 아래에 따로 둔다. 확인할 조건 이름과 "추정"을 함께 적는다(2026-10-24. 이전에는 위치를 정하지 않았다). 후보 사이의 우열 표시는 [매칭 원칙](../recommendation/README.md#매칭-원칙)을 따른다.

## 행동

- 저장: 북마크. 취향 변경 없음.
- 다른 후보 보기: 이번 추천 묶음에서만 넘긴다. 이유는 선택 입력이다. 영구 제외 없음. 이미 보여준 도시를 빼고 같은 원칙(순서대로 2곳 + 조건부 탐색 1곳)으로 다시 고른다(2026-10-17).
- 다시 추천하지 않기(이전 이름: 계속 추천하지 않기): 카드 메뉴에 둔다. 저장 안내·되돌리기 제공.
- 아쉬운 점 알려주기(이전 이름: 이유 알려주기): 카드 메뉴에서 도시를 대상으로 자유문장 피드백을 입력한다. 입력 자체로 제외하지 않고 아래 범위 해석 후 저장 내용·되돌리기를 표시한다. 건너뛸 수 있으며 상세의 정보 질문과 구분한다.
- 상세: 이번 여행에 맞는 이유, 실제로 할 수 있는 경험, 안 맞을 수 있는 점과 확인할 조건, 예상 비용, 궁금한 점 질문하기, 이곳으로 여행 등록의 순서로 보여준다(2026-10-24 예상 비용 추가). 제외한 도시면 위쪽에 제외 상태와 "제외 풀기"를 보여준다.
- 새 여행 시작: 이번 조건과 이번 여행 제외를 새로 시작. 평소 선호·계속 제외 유지.

“도쿄는 별로예요”는 계속 제외하고 저장 안내·되돌리기를 제공한다.
“이번엔 너무 비싸요”는 제외나 기억으로 저장하지 않는다. 사용자가 예산 조건을 고친다.
“나는 원래 붐비는 곳을 싫어해요”는 평소 선호로 자동 저장하고 내용·되돌리기를 표시한다.
모호해서 적용 범위가 달라지는 경우에만 한 가지 확인 질문을 한다.

다른 후보 보기나 제외로 카드가 빠지면 LLM이 고른 다음 도시로 채운다(2026-10-17 변경: 코드가 정한 순서의 다음 도시로 채운다. 같은 묶음이 소진되면 다음 묶음으로 넘어가고, 이번 조회 중 보여준 카드는 다시 나오지 않는다). 남은 도시가 없으면 채우지 않는다. 다른 카드는 유지한다.
예산·시기·기간 수정은 LLM이 이미 반환한 도시들을 재검사한다. 목적·자유문장 변경으로 새 선택이 필요하면 새 추천을 받는다. 조건에 의존한 설명은 변경 뒤 그대로 적합한 설명으로 쓰지 않는다.
저장 성공과 재추천 성공은 구분한다. 생성 실패로 사용자의 제외를 되돌리지 않는다.

## 상세와 질문

상세는 위 행동 절의 순서로 보여주고, 핵심 경험은 저장된 도시 자료에서 가져오며(2026-10-17: LLM이 요청에 맞춰 경험을 고르고 설명하는 방식과 비교한 A/B 실험에서 바꿀 근거가 부족해 현 구성을 유지한다. 사람 재판독 전의 잠정 결정이다) 유효한 개인화 설명은 받은 결과에서 재사용한다.
무엇을 할 수 있는지·왜 맞는지·안 맞을 수 있는 점·출처를 제공한다.
추가 질문은 저장 자료와 허용된 검색의 근거를 사용하며 일반 조언의 사실 전제도 검증 대상이다. 상세 질문의 횟수는 무료 월 3회, 구독 월 30회이며 무료 한도는 기기(Firebase 익명 ID) 단위로 센다([구독](../recommendation/README.md#2026-10-07-추가-결정-구독-자료-배포-저장)). 추천 상세 밖(예: 저장한 도시)에서도 질문할 수 있게 할지와 목록 밖 도시 질문의 지원은 [미정](../recommendation/README.md#미정)이다. 변동 사실이 미확인이면 공식 확인 경로로 안내한다. 답변은 근거·조언·미확인을 구분해 보여준다. 이 구분 원칙은 정해졌고 [설명 계약](../recommendation/sources.md)을 따른다. 세 표현을 그대로 섹션 제목으로 쓸지는 정하지 않았다. 모델의 분류를 그대로 배지로 표시하지 않으며 최종 문구·배치는 U3에서 검토한다.
열람·질문만으로 취향을 변경하지 않는다. 상세에서도 제외 상태를 확인·해제할 수 있다.

제휴 링크는 추천 결과와 독립적으로 연결하고 제휴 관계를 표시한다.
사용자에게 필요한 이유·유의점을 광고 뒤에 숨기지 않는다.
추천 상세의 정확한 답변 규칙은 [추천 설명](../recommendation/sources.md)을 따른다.

## 목록 밖 도시와 등록 연결

의도별 처리는 [목록에 없는 도시](../recommendation/README.md#목록에-없는-도시)를 따른다. 이미 정한 목적지라면 등록 화면으로 이동할지 묻고, 선택한 경우에만 초안을 연다. 검토 중인 도시는 “생각 중인 곳”으로 남겨 앱 추천과 구분한다. 함께 갈 도시 추천을 MVP에서 제공하는 것처럼 표시하지 않는다.
이번 요청으로 과거 제외의 예외가 적용되면 그 사실을 알린다. 저장된 계속 제외 설정 자체는 유지한다.

## 저장 목록과 제외 목록

북마크와 제외는 독립적이다. 저장 목록에 제외 상태를 표시하며, 북마크 해제가 제외 해제는 아니다.
추천 이유는 생성 시점 정보를 구분하고, 조건이 달라졌다면 최신 확인 경로를 제공한다.
도시를 여행으로 등록할 수 있지만 아직 정하지 않은 날짜·동행을 자동 확정하지 않는다.

## 실패·동시 변경

- 후보 부족: 조건에 맞는 수만 카드로 보여주고 어떤 조건이 제한했는지 설명한다. 하나도 없을 때의 동작은 [미정](../recommendation/README.md#미정)이다.
- 오프라인/호출 실패: 유효한 기존 결과를 재사용한다. 삭제한 기억이나 제외한 카드를 복원하지 않는다. 새 추천은 받을 수 없고 재시도 경로를 안내한다.
- 호출 한도 소진(2026-10-17 사용자 결정): 마지막으로 받은 추천 화면을 그대로 보여준다. 무료 사용자가 “추천 새로 받기” 같은 새 호출 버튼을 누르면 구독 화면으로 보낸다. 한도의 수치는 [구독 결정](../recommendation/README.md#2026-10-07-추가-결정-구독-자료-배포-저장)을 따른다. 구독 화면은 미구현이며, 구독자가 한도를 다 쓴 경우의 안내는 정하지 않았다.
- 입력 변경 중 도착한 이전 응답: 폐기한다.
- 추천 카드에 이번 여행 예외를 적용한 뒤에도 제외된 도시·알 수 없는 ID·잘못된 근거가 있으면 검증 실패 처리한다. “생각 중인 곳”과 등록 초안은 추천 카드와 별도로 확인한다.
- 앱 재시작: 이번 여행 조건·제외 유지.
- 제외 해제: 다음 추천에 포함될 수 있을 뿐 자동 1위가 되지 않는다.
