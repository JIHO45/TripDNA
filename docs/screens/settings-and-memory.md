# 설정·기억·제외·데이터

2026-10-08 정합성 보완: 반영한 기억과 영구 선호, 이번 여행 제외 예외, 전송·집계 안내를 구분했다.
상태: 기존 로컬 기능을 유지하며 새 기억 관리의 목표 동작을 정의한다.
기준: [사용자 기억](../recommendation/memory.md), [추천 구조](../recommendation/README.md), [저장](../data/storage-and-privacy.md).

## 로그인과 저장 안내

로그인 없이 이용할 수 있다. Apple 로그인 성공을 클라우드 백업 완료라고 설명하지 않는다.
현행 여행·사진은 기기에 저장되며 다른 기기에서 자동 복구되지 않는다.
현행 정책에 따라 별도 로그아웃 버튼 대신 데이터 삭제 경로를 제공한다.
LLM 호출의 인증·남용 방지는 [서버 결정](../recommendation/README.md#2026-10-07-추가-결정-구독-자료-배포-저장)을 따르며 로그인 화면을 강제하지 않는다.

## 기억하는 취향

저장된 내용, 평소/이번 여행 범위, 언제 어떤 답에서 왔는지 보여준다.
사용자가 수정·삭제할 수 있다. 숫자 축을 맞추도록 요구하지 않는다.
명시적 평소 취향의 자동 저장은 안내와 되돌리기를 제공한다.
애매한 해석은 확인 전 확정 기억으로 표시하지 않는다. 평가 메모에서 호출 때 만든 “반영한 기억”은 추천 결과의 설명이며 영구 선호 목록에 자동 추가하지 않는다. 원문 수정·삭제는 해당 도시 평가로 연결한다.

## 추천에서 제외한 곳

도시/나라와 이번 여행/계속 적용을 구분해 표시한다. 해제 버튼을 제공한다.
도쿄의 이유 없는 부정 반응은 계속 제외, “이번에는”이라는 범위가 있으면 이번 여행 제외다.
나라 제외를 해제해도 별도로 저장된 도시 제외는 유지한다.
도시 상세 열람·북마크는 제외 해제가 아니다.
이번 요청으로 적용한 제외 예외를 원래 계속 제외와 구분해 보여준다. 새 여행 시작에서는 이번 여행 예외도 초기화하며 계속 제외·평소 선호는 유지한다.

## 데이터와 권한

사진 접근과 자동 후보 동의는 구분해 관리한다.
평가 메모 원문의 LLM 전송과 목록 밖 도시 요청의 서버 집계에 대한 안내에 접근할 수 있게 한다. 목적·동의·삭제 범위는 [데이터 경계](../data/storage-and-privacy.md)를 따른다.
기억 하나 삭제, 여행/평가 삭제, 계정 및 전체 데이터 삭제의 영향을 구분한다.
삭제된 증거에서 나온 요약·추천 캐시도 재구성한다.

삭제 성공은 실제 저장소 처리 성공 뒤 표시한다. 실패 시 삭제되지 않은 범위와 재시도를 안내한다.
서버 보관이 도입되면 [데이터 경계](../data/storage-and-privacy.md)의 서버 삭제 절차도 연결한다.
아직 없는 백업·기기 간 복구·동기화를 UI에서 약속하지 않는다.
