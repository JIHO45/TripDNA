# 여행 평가·수정

2026-10-08 정합성 보완: 도시별 평가와 호출 시 메모 해석에 맞춰 이전 태그·사전 자동 해석 문장을 정리했다.
2026-10-08 변경: 태그 선택을 없애고 도시마다 별점과 메모로 받는다. 이전 태그 입력 문장은 제거하고 기존 기록 보존은 이관 원칙에 연결했다.
상태: 목표 동작. 기준: [사용자 기억](../recommendation/memory.md).
평가를 마치면 반드시 축이 움직이거나 추천이 교체된다는 약속을 제거한다.

## 입력

방문한 도시마다 별점, 좋았던 점 메모, 아쉬웠던 점 메모를 받는다. 도시가 여러 곳이면 도시별로 페이지를 나눈다. 메모는 선택이다. 등록할 때 붙인 여행 컨셉을 여기서 고칠 수 있다. 메모는 [다음 추천의 입력](../recommendation/README.md#지난-여행의-기억)이 된다.
건너뛰기와 나중에 하기를 제공하고, 완료 시간을 검증하지 않고 보장하지 않는다.
미입력은 미상이다. 평가를 건너뛰면 방문 사실만 남긴다.

직접 비교를 제공하는 경우 첫 여행에는 생략한다.
“비슷했어요”는 동등 평가, “기억 안 나요”는 미상으로 구분한다.
비교 결과만으로 성향 항목의 확신을 올리지 않는다.

## 경험의 귀속

새 평가는 해당 도시 페이지에 귀속한다. 도시 식별이 불분명하거나 기존 여행 전체 평가만 있으면 그 정밀도를 보존한다.
전체 여행/도시 모름을 허용하고, 모르면 베스트 도시로 자동 배분하지 않는다.
여행 전체의 평가를 모든 방문 도시에 복제하지 않는다.
기존 나라만 있는 기록은 그 정밀도대로 보존한다.

새 태그 선택은 받지 않는다. 메모에는 도시의 대표 경험이나 컨셉 목록 밖 내용도 적을 수 있다. 기존 태그의 보존·해석은 [이관 원칙](../recommendation/memory.md#기존-데이터-이관)을 따른다.

## 저장과 기억

“이번 여행 음식이 좋았어요”는 해당 경험의 평가로 보존한다.
MVP에서는 평가 저장 시 메모를 해석해 별도 취향 요약을 만들지 않는다. 다음 추천에서 원문을 참고하고, 그때 반영한 내용은 [지난 여행의 기억](../recommendation/README.md#지난-여행의-기억)에 따라 보여준다. 추천 대화에서 사용자가 직접 확정하는 평소 선호와 구분한다.
“재방문하지 않겠다”만으로 영구 추천 제외나 새로운 곳 선호를 만들지 않는다. 제외 요청은 별도 행동이다.

저장 성공 뒤 무엇을 기록했는지 보여준다. 단순 축 델타 연출로 학습을 과장하지 않는다.
추천을 바꿀 근거가 생겼다면 다음 추천에 반영한다. 생성 실패 시 평가 저장 성공과 구분한다.
대표 사진 선택과 공유는 평가 뒤 선택 단계로 유지한다.

## 수정·삭제와 실패

제출 후에도 평가 수정·삭제를 허용한다. 랭킹 조정은 잘못된 답을 수정하는 대체 수단이 아니다.
수정 전후의 관계를 추적해 삭제한 근거가 기억·캐시·공유 요약에 남지 않게 한다.
동일 수정이 중복 저장되어 증거가 늘어나지 않도록 한다.
오프라인에는 기록을 로컬에 저장할 수 있으나 LLM 신규 추천이 완료됐다고 표시하지 않는다.
