# 과거·예정·현재 여행 등록

상태: 기존 여행 기능을 유지하고 도시 식별·취향 해석을 갱신하는 목표 동작.
기준: [핵심 설계](../recommendation/architecture.md) 3·4절.

## 목록과 등록

현재·예정·지난 여행 목록과 등록 진입을 유지한다.
직접 입력과 사진첩 찾기를 제공하며 사진 권한은 선택한 경로에서만 요청한다.
여행 구간마다 나라, 알고 있는 도시, 기간을 기록한다. 다국가·다도시 여행을 한 여행의 구간으로 표현한다.

도시가 추천 DB 밖이거나 미확인이어도 여행 기록을 허용한다.
동명 도시는 나라·지역으로 확인하고, 불명확하면 원문만 보존한다.
출발/종료일이 추정이면 정밀도를 보존하며 알림용 날짜를 실제 방문 사실로 둔갑시키지 않는다.
종료일보다 시작일이 늦는 등 모순은 입력 위치에서 알려준다.

## 사진첩 후보

기기에서 위치·날짜로 방문 후보를 찾고 사용자 확인 뒤 저장한다.
합치기·나누기·잘못된 여행 제외·대표 사진 교체를 제공한다.
환승·거주·사진 수로 여행 만족도나 취향을 추론하지 않는다.
추천용으로 전송할 확인된 도시 정보와 원본 사진/위치 데이터의 경계를 안내한다.

## 동행·평가

동행과 여행/출장 등 목적은 해당 여행의 사실이다. 가족 여행 한 번으로 평소 취향을 바꾸지 않는다.
과거 여행에는 만족도·좋았던/아쉬웠던 경험을 선택적으로 기록할 수 있다.
미평가 여행을 중간 만족도로 채우지 않는다.
등록만으로 “취향이 바뀌었다”거나 “추천 정확도가 올랐다”고 단정하지 않는다.

추천에서 도시를 선택해 등록할 때 사용자가 확정한 정보만 채운다.
추천용 이번 여행 조건과 실제 여행 원장을 구분하며, 조건 입력만으로 방문 기록을 만들지 않는다.

## 상태와 권한

예정 → 현재 → 종료 → 평가/평가 건너뛰기 흐름을 유지한다.
수정·삭제·대표 사진 변경·공유 경로를 제공한다.
첫 예정/현재 여행 등록 뒤 맥락을 설명하고 사용자가 선택한 경우 알림 권한을 요청한다.
루트 README의 제외 범위에 따라 위치 권한·도착 자동 감지를 추가하지 않는다. 종료일 기반 알림과 수동 등록을 사용한다.

오프라인 등록은 로컬 저장이다. 클라우드 동기화 대기라고 표시하지 않는다.
저장 실패 시 입력을 보존한다. 여행 삭제 뒤 파생 기억 처리는 [증거와 이관](../recommendation/preference-evidence.md)을 따른다.
