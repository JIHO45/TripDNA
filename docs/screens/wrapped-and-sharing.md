## 연간 회고

기존 6장 구성과 12월 15일~다음 해 1월 15일의 시즌 진입을 유지한다. 시즌 밖에도 홈 진입은 숨기지 않는다. 지난 해 Wrapped가 있으면 다시 보기를, 없으면 올해 Wrapped가 열리는 날을 보여준다. 지난 해 Wrapped는 그해 기록으로 다시 만든다.
해당 연도 여행이 있어야 하며, 12월에는 “올해 지금까지”, 1월에는 회고 연도를 명시한다.
개별 여행 공유와 취향 지문 공유는 연중 제공한다.

회고 소재는 여행 수·확인된 방문지·사용자가 평가한 여행 랭킹·그해 여행의 컨셉이다. 취향 카드는 그해에 가장 많이 나온 주 컨셉을 보여준다.
취향 문장은 해당 시점의 증거 범위를 지킨다.
올해에 대한 근거가 없으면 “올해 자연형으로 변했어요” 같은 변화를 만들지 않는다.
현재 입력으로 과거 전체의 성격을 다시 써 놓고 당시 취향이었다고 설명하지 않는다.

여행 1건이면 비교 표현을 줄인다. 데이터가 없으면 추정으로 카드를 채우지 않는다.
개인용 회고의 사진은 기기에 보관된 기록을 사용하며, 공유 이미지의 공개 범위와 분리한다.

## 공유 이미지

현행 공개 범위를 유지한다.

- 공유 전 미리보기와 공개 내용 확인.
- 국가 이름은 기본 숨김이며 공개 설정 변경 후 다시 확인.
- 정확한 날짜·도시·동행인·개인 사진은 현재 내보내기 범위에 추가하지 않는다.
- TripDNA 이름과 설정된 설치 링크를 표시한다. 없는 설치 주소를 생성하지 않는다.
- 지문의 표현은 [취향 지문](home-and-fingerprint.md#취향-지문)을 따른다. 공유 카드의 배치는 별도 디자인 작업이다.

도시 중심 추천이 곧 방문 도시 공개 동의를 뜻하지 않는다.
개인 사진을 공유하는 확장은 별도 결정 전까지 기존 이미지 내보내기에 섞지 않는다.

## 저장·갱신

기록 수정·기억 철회 뒤 앱 안의 회고/공유 미리보기를 다시 만든다.
이미 외부에 저장·전송한 이미지를 앱이 회수했다고 표시하지 않는다.
이미지 저장 권한 거부·렌더링 실패·공유 시트 취소를 성공으로 기록하지 않는다.
시즌 밖 개발 미리보기를 일반 사용자 기능이라고 문서화하지 않는다.
