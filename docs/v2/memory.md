# 사용자 기억·조건·제외와 이관

상태: v2 구현 목표. 이전: [직접 증거](../recommendation/preference-evidence.md), [경험 어휘](../recommendation/experience-vocabulary.md), [기억 정책](../recommendation/architecture.md#6-피드백기억제외-정책).
이 문서는 사용자 정보의 **의미와 적용 범위**를 담당한다. 저장 위치는 [저장 계약](../README.md#storage), 버튼 배치는 [화면](../README.md#screens)으로 연결한다.

## 증거와 조건

내용, 원문/선택지, 출처, 시점, 적용 범위, 활성/철회 상태를 보존한다. 직접 답변과 모델 해석을 구분하며 요약에는 원본 연결을 남긴다.

- 방문은 위치·기간의 사실이다. 사진·국가 방문만으로 만족·계획성·사교성을 추론하지 않는다. 나라만 알면 도시 전체 방문으로 확대하지 않는다.
- 여행 평가는 해당 여행/도시/경험의 좋음·아쉬움이다. 이유가 없으면 특성으로 분해하지 않는다. 전체 평가를 모든 방문 도시에 복제하지 않는다.
- 평소 선호는 일반적인 선호를 명시한 진술이다. 자동 저장 후 내용·범위·되돌리기를 보여준다. 질문·가정·인용은 선호 진술이 아니다.
- 이번 조건은 동행·출발지·날짜·기간·예산·목적이다. 미입력은 모름이며 과거 평균으로 채우지 않는다. 예산은 통화·인원·포함 항목을 구분한다.
- 이번에 명시한 목적은 평소 선호보다 우선한다. 확정 제외와 필수 조건은 항상 지킨다. 선호와 필수 조건이 모호하고 추천을 크게 바꾸면 한 가지만 확인한다.
- 북마크는 관심 후보 보관이다. 질문·열람·저장·미반응으로 장기 선호나 제외 해제를 만들지 않는다.
- 여행 비교는 상대 선호 관계다. 이유 없이 모든 항목의 확신을 올리지 않는다. 재방문 의향은 해당 대상의 의향이며 영구 제외나 일반적 새로움 선호가 아니다.

방문 도시도 기본 추천 대상이며 “새로운 곳만 보기”에서는 확인된 방문 도시만 제외한다. 나라만 아는 방문을 모든 소속 도시 방문으로 확대하지 않는다.

현재 여행은 재시작 후에도 유지한다. “새 여행 시작”은 이번 조건·이번 여행 제외를 새로 시작하며 평소 선호·계속 제외는 보존한다.

## 제외와 자유문장 해석

대상 종류와 ID, 도시/나라 범위, 이번 여행/계속 적용, 이유 원문, 시점, 해제 상태를 보존한다.

- “도쿄는 별로예요”: 이유·기간이 없으면 도쿄 계속 제외. 다른 도시나 경험 선호로 확대하지 않는다.
- “이번엔 너무 비싸요”: 해당 후보를 이번 여행에서 제외하고 비용 이유를 기록한다. 예산 숫자·고물가 도시 일괄 제외를 만들지 않는다.
- “일본은 추천하지 마”: 일본 소속 후보 제외. 나라 제외 해제는 별도로 저장한 도시 제외를 지우지 않는다.
- “나는 원래 붐비는 곳을 싫어해요”: 평소 혼잡 회피. 새로운 사람과의 만남을 싫어한다고 해석하지 않는다.
- “음식은 좋았지만 줄은 싫었어요”: 음식 긍정과 대기 회피를 각각 해당 범위로 보존한다.
- “다른 후보 보기”: 현재 요청의 대안 탐색이며 영구 제외가 아니다.

제외·기억은 저장 내용과 되돌리기를 안내하고 목록에서 해제·수정할 수 있다. 저장 실패 시 “기억했어요”라고 표시하지 않는다. 모호한 범위는 확인 전 확정하지 않는다.

## 경험 어휘

저장 ID·라벨의 원문은 [경험 분류 JSON](../../data/experience-categories.json)이다. 여기에서 목록을 복사하지 않는다. 기존 5축 서명을 새 선호 계산에 재사용하지 않는다.

도시·자연은 동시에 좋아할 수 있다. 혼자 있는 시간·기존 동행·새 사람 만남은 반대축이 아니다. 밤 문화·음악·술, 자연 풍경·등산 강도를 동일시하지 않는다. 분류 밖 자유문장과 세부 활동을 보존한다. 미선택·모름은 싫어함이 아니며 “둘 다 좋아함”과 구분한다.
ID 의미를 재사용하지 않고 분류 변경 시 버전·기존 데이터 이관 여부를 명시한다. 질문의 문구와 선택 UI는 [화면](../README.md#screens)에 둔다.

## 수정·철회

동일 원문을 반복 요약해도 증거가 늘어난 것이 아니다. 같은 범위의 명시적 정정은 이전 내용을 대체하며 상황이 다른 선호는 함께 보존한다.
평가 수정·삭제 뒤 관련 기억·추천·공유 요약을 재구성한다. 사용자가 별도로 확정한 평소 선호까지 자동 삭제하지 않고 삭제 범위를 안내한다. 철회한 정보가 캐시·과거 요약에서 복원되지 않게 한다.

## 기존 기록 이관

1. 여행·구간·평가·퀴즈 답·북마크·제외 원본을 보존한다. 기존 국가 북마크를 임의 도시로 바꾸지 않는다.
2. 국가 평균이 섞인 파생 5축 값을 새 선호로 변환하지 않는다. 질문/선택지 뜻을 복원할 수 있는 원본 답·태그만 해당 범위로 옮긴다. 불명확하면 미해석으로 보존한다.
3. 도시를 명확히 식별할 때만 ID에 연결한다. 모호한 원문·나라만 있는 방문은 정밀도를 유지한다.
4. 나라 제외와 기존 기한을 보존한다. 옛 세션 제외는 과거 기록으로 남기고 새 활성 제외로 승격하지 않는다. 기존 기한 있는 제외까지 비활성화하지 않는다. 차이를 안내하고 새 범위 선택을 허용한다.
5. 국가 모델 노출은 과거 기록으로 유지하고 새 도시 성과에 무표시 합산하지 않는다.
6. 반복 이관의 중복 방지·저장 버전별 변환·실패 시 원본 보존을 검증한다. 별도 이벤트 소싱 시스템은 요구하지 않는다.
