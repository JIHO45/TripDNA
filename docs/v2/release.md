# 출시 빌드 검증

상태: v2, **통과 기록이 아닌 완료 조건**이다. 이전: [전환 체크리스트](../v1/progress.md). 작업 상태·실행 결과는 [TODO](../TODO.md)에 남긴다.

## 선행 조건

[평가](../README.md#evaluation)에서 채택·공개 범위를 결정한 뒤 저장·서버·화면을 연결한다. 기존 국가 추천의 수정/검증과 도시·LLM 도입은 별개다. 새 호출 성공이나 문서 작성만으로 전환을 완료 처리하지 않는다.
기존 추천 경로·번들 의존성 제거는 홈·온보딩·추천·상세·공유의 호출부와 이관을 검증한 뒤 진행한다. 역사 기록 해석에 필요한 타입까지 무조건 삭제하지 않는다.

## 출시할 빌드에서 확인

- 빌드와 관련 단위/UI 검사, 재시작 후 원본 보존·이관·삭제. 명령은 루트 [AGENTS.md](../../AGENTS.md)를 따른다.
- [평가의 회귀 시나리오](../README.md#evaluation), 새 방식의 실제 품질·비용·지연 기준.
- [기억 계약](../README.md#memory)의 저장·수정·철회·범위와 [추천 계약](../README.md#recommendation)의 동시 변경·검증 실패·오프라인·호출 한도.
- [저장 계약](../README.md#storage)의 키 보호·전송 안내·남용 방지·로그 보관·실제 삭제와 복구 안내.
- [화면 계약](../README.md#screens)의 권한 거부·빈 상태·접근성·공유 미리보기, 실기기 내보내기와 데이터 유지.
- 제휴를 공개하는 경우 [제휴 계약](../README.md#affiliates)의 승인·목적지·표시·sub-id·실기기 귀속. 승인 대기를 추천 실험의 선행 조건으로 두지 않는다.

## 제출·운영 준비

선택 모델·검색 서비스의 실제 요금과 한도·장애 대응, 개인정보 처리방침, 사진 권한 문구, `PrivacyInfo.xcprivacy`, 앱 아이콘, `TripDNAShareURL`, 메타데이터·스크린샷·심사 자료를 확인한다. 제출 시점 공식 요건을 다시 확인하고 미확인 항목은 미확인으로 남긴다.
실행하지 못한 검사는 이유·남은 조치를 기록하며 과거 통과를 새 빌드 결과로 복사하지 않는다. 공개 시점·범위는 사용자 결정으로 확정한다. 출시 후 수집 가능한 지표만 [계측](../README.md#metrics)에 따라 관찰한다.
